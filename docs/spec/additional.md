# 追加辞書

利用者が基本辞書に足して使う辞書。何を持つかは [基本辞書と、それに足す追加辞書に分ける](../adr/20261004-split-into-base-and-additional-dictionaries.md) による。

## 項目

- 項目の種類、コスト、書き出しの形は [辞書の項目](dictionary.md) と同じ。説明の行の表示名は、追加辞書の表示名。
- 基本辞書と同じ（読み, 表記, 活用型）の行は持たない。
- 活用しない語の行のうち、基本辞書だけを読ませた Kanaemi がその読みで同じ表記を候補に出すものは持たない。送り仮名付きの語の行は、送り仮名を指定して打ったときで確かめる。
- UniDic の語は持たない。
- 地名の辞書は、郵便番号データの地名から作る（[地名は郵便番号データの一覧から取る](../adr/20261004-take-place-names-from-the-postal-code-list.md)）。
- 送り仮名の揺れの辞書（`okurigana`）は、基本辞書の文書の単位のうち、送り仮名の揺れ（[辞書の項目](dictionary.md#送り仮名の揺れ)）だけから作る。足切りとコストは、その単位の中で基本辞書と同じに決める。ほかの辞書はどれも送り仮名の揺れを持たない。

## 設定

追加辞書ごとに `additional/<名前>/` を置く。

| ファイル | 中身 |
| --- | --- |
| `label.txt` | 表示名（`鉄道`、`2026年の新語`）。辞書の説明の行に使う |
| `wikipedia.txt` | Wikipedia の記事から作る辞書だけ。記事のカテゴリに当てる正規表現。1 行に 1 つ |
| `wikipedia-since.txt` | その年の新語の辞書だけ。候補にする記事の最初のページ ID |

設定のファイルで素材が決まらない辞書（地名、法律）は、名前ごとにコードが素材を決める。

## 分野の辞書

`wikipedia.txt` のある辞書は、日本語版 Wikipedia の記事のうち、カテゴリのどれかが `wikipedia.txt` のどれかに当たるものを文書にして作る。

- 曖昧さ回避の記事は使わない。
- 文書に語として出る記事の見出し（中道改革連合 のような、解析器が複数の語に分ける複合語）も、活用しない語として足す。読みは記事の本文から取る。

## その年の新語の辞書

`wikipedia-since.txt` のある辞書は、その年に新しく作られた記事の見出しを候補にし、その年の Web の文章に語として出るものから作る。

- その年の文章で、それより古い文章よりはっきり多く使われる見出しだけを残す。古くからある語が、その年によく出ただけでは入れない。
- `additional/<年>/` がなければ、表示名を `<年>年の新語`、カテゴリをすべてとし、`wikipedia-since.txt` を Wikipedia の記事の作成記録から、その年に最初に作られた記事のページ ID として作る。その年に作られた記事がまだなければ作らない。
