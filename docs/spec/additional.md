# 追加辞書

利用者が基本辞書に足して使う辞書。何を持つかは [基本辞書と、それに足す追加辞書に分ける](../adr/20261004-split-into-base-and-additional-dictionaries.md) による。

## 項目

- 項目の種類、コスト、書き出しの形は [辞書の項目](dictionary.md) と同じ。説明の行の表示名は、追加辞書の表示名。
- 基本辞書と同じ（読み, 表記, 活用型）の行は持たない。
- 活用しない語の行のうち、基本辞書だけを読ませた Kanaemi がその読みで同じ表記を候補に出すものは持たない。送り仮名付きの語の行は、送り仮名を指定して打ったときで確かめる。
- UniDic の語は持たない。
- 地名の辞書は、郵便番号データの地名から作る（[地名は郵便番号データの一覧から取る](../adr/20261004-take-place-names-from-the-postal-code-list.md)）。
- 送り仮名の揺れの辞書（`okurigana`）は、基本辞書の文書の単位のうち、送り仮名の揺れ（[辞書の項目](dictionary.md#送り仮名の揺れ)）だけから作る。足切りとコストは、その単位の中で基本辞書と同じに決める。ほかの辞書はどれも送り仮名の揺れを持たない。

## 一覧から作る辞書のコスト

人名・地名・駅名の辞書は、一覧の中の割合から決めたコストを、辞書の中で最も安い項目が、基本辞書の文章に 1 回出た語のコストになるように、すべての項目で同じだけずらす。辞書の中のコストの差は変えない。どう決めるかは [一覧から作る追加辞書のコストは、基本辞書の文章に 1 回出た語のコストから始める](../adr/20261013-start-list-dictionary-costs-at-a-word-seen-once-in-the-base-text.md) による。

- 基本辞書の文章に 1 回出た語のコストは、`cost_of(1, 基本辞書が数えた単位の数)`。
- `just dictionary` は、このコストを `build/dictionaries/base-seen-once.txt` に、`just dictionary --train-only` は `build/dictionaries/base-train-seen-once.txt` に書く。中身は 10 進の数 1 つと改行。
- `just additional` は前者を、`just additional --train-only` は後者を読む。読めなければ、人名・地名・駅名の辞書を作らずに失敗させる。
- 分野の辞書、その年の新語の辞書、送り仮名の揺れの辞書、記号・絵文字・顔文字の辞書のコストはずらさない。

## 設定

追加辞書ごとに `additional/<名前>/` を置く。

| ファイル | 中身 |
| --- | --- |
| `label.txt` | 表示名（`鉄道`、`2026年の新語`）。辞書の説明の行に使う |
| `wikipedia.txt` | Wikipedia の記事から作る辞書だけ。記事のカテゴリに当てる正規表現。1 行に 1 つ |
| `wikipedia-since.txt` | その年の新語の辞書だけ。候補にする記事の最初のページ ID |

設定のファイルで素材が決まらない辞書（地名、法律、送り仮名の揺れ、記号、絵文字、顔文字、人名、駅名）は、名前ごとにコードが素材を決める。

## 分野の辞書

`wikipedia.txt` のある辞書は、日本語版 Wikipedia の記事のうち、カテゴリのどれかが `wikipedia.txt` のどれかに当たるものを文書にして作る。

- 曖昧さ回避の記事は使わない。
- 文書に語として出る記事の見出し（中道改革連合 のような、解析器が複数の語に分ける複合語）も、活用しない語として足す。読みは記事の本文から取る。

## その年の新語の辞書

`wikipedia-since.txt` のある辞書は、その年に新しく作られた記事の見出しを候補にし、その年の Web の文章に語として出るものから作る。

- その年の文章で、それより古い文章よりはっきり多く使われる見出しだけを残す。古くからある語が、その年によく出ただけでは入れない。
- `additional/<年>/` がなければ、表示名を `<年>年の新語`、カテゴリをすべてとし、`wikipedia-since.txt` を Wikipedia の記事の作成記録から、その年に最初に作られた記事のページ ID として作る。その年に作られた記事がまだなければ作らない。

## 記号・絵文字・顔文字の辞書

記号の辞書（`symbol`）、絵文字の辞書（`emoji`）、顔文字の辞書（`emoticon`）は、Mozc の表から作る。どう決めるかは [記号・絵文字・顔文字は Mozc の一覧から取り、それぞれ追加辞書にする](../adr/20261007-take-symbols-emoji-and-emoticons-from-mozc.md) による。

`just additional-fetch` は、Mozc の表を、基本辞書の単漢字の表と同じ commit で `build/additional/raw` に取る。`just additional-docs` は、それを辞書ごとに `build/additional/<名前>/` に書き出す。

| 辞書 | 表 | 表記の列 | 読みの列 |
| --- | --- | --- | --- |
| 記号 | `src/data/symbol/symbol.tsv` | 2 列目 | 3 列目 |
| 絵文字 | `src/data/emoji/emoji_data.tsv`、`src/data/emoji/manual_emoji_data.tsv` | 2 列目 | 3 列目 |
| 顔文字 | `src/data/emoticon/emoticon.tsv` | 1 列目 | 2 列目 |

- 読みの列は、空白（全角の空白を含む）で区切った読みの並び。1 つの読みごとに、表記との組にする。`#` で始まる行と、表記の列が空か `#` で始まる行は読まない。記号の表の 1 行目（見出しの行）は読まない。
- 記号の表の変体仮名（U+1B000〜U+1B16F の字を含む表記）は取らない。
- 読みは、既定のローマ字の表で打った形に直す。カタカナはひらがなに、英字を除く ASCII の印字可能な文字は全角に、`- , . [ ] / ~` は `ー 、 。 「 」 ・ 〜` にする。直した後に、ひらがな、長音符、`、。「」・〜`、英字を除く全角の ASCII（U+FF01〜U+FF5E）のほかの文字を含む読みは捨てる。
- 読みと表記が同じ組と、同じ組の 2 度目からは書かない。
- コストは、同じ読みの組を表の順に `8192`、`8193`、… とする（16383 で止める）。絵文字は `emoji_data.tsv` の後に `manual_emoji_data.tsv` を続けた順。
- 語の形の決まり（空白を含む表記、`〜` で終わる表記を外す）は当てない。外す語（訂正の語）は当てる。

## 人名の辞書

人名の辞書（`person`）は、Wikidata の人物の読み仮名から作る。どう決めるかは [人名は Wikidata の読み仮名から取り、人名の追加辞書にする](../adr/20261007-take-person-names-from-wikidata-into-their-own-dictionary.md) による。

`just additional-fetch` は、QLever（`https://qlever.dev/api/wikidata`）に、人間（P31 が Q5）で読み仮名（P1814）を持つ項目の 項目・読み仮名・日本語のラベル・サイトリンク数・日本語版ウィキペディアの記事・生年（P569）を問い合わせ、結果の TSV を `build/additional/raw` に取る。QLever の索引は更新されるので、取り直しを指定するまで取り直さない。`just additional-docs` は、それを `build/additional/person/people.tsv` に書き出す。

- 1 つの項目の行をまとめて 1 人とする。読み仮名はすべて、サイトリンク数は最も大きいもの、生年は最も早いものを使う。
- ラベルは、末尾の括弧の添え書きを除く。漢字を含まないラベルと、かな・漢字・`々`・長音符のほかの字を含むラベルの人物は使わない。
- 読み仮名は空白（全角の空白を含む）で区切り、それぞれから `・` とゼロ幅の空白を除き、カタカナをひらがなに、ゐ・ゑ を い・え にする。かな以外の文字が残る読み仮名は使わない。

### 読み仮名のない人物

読み仮名のない人物は、日本語版ウィキペディアの記事の冒頭の読みで補う。どう決めるかは [読み仮名のない人物の人名は、Wikipedia の記事の冒頭の読みで補う](../adr/20261012-supplement-person-names-with-wikipedia-readings.md) による。

`just additional-fetch` は、QLever に、人間（P31 が Q5）で日本語版ウィキペディアの記事を持ち、読み仮名（P1814）を持たない項目の 項目・日本語のラベル・サイトリンク数・日本語版ウィキペディアの記事・生年（P569）を問い合わせ、結果の TSV を `build/additional/raw` に取る（`wikidata-people-unread`）。取り直しを指定するまで取り直さない。

`just additional-docs` は、記事の URL のパスを戻し `_` を空白にしたものを記事の見出しとし、Wikipedia のダンプ（基本辞書の `build/raw` の `wikipedia-ja`）の記事（リダイレクトを除く名前空間 0 のページ）のうち、見出しがそのどれかのものから読みを取る。ダンプは分野の辞書の記事と同じ読み通しで読む。

- 本文からコメントを除き、最初の節見出し（`==` で始まる行）の前までを冒頭とする。
- 冒頭の太字（`'''…'''`）のうち、両端の `'` と空白（全角の空白を含む）を除いて整えると、末尾の括弧の添え書きを除いて整えた見出しと同じになる最初のものを取る。その直後（`'` と空白を挟んでよい）の `（` か `(` から、`、,，）);；` の前までを読みとする。
- 読みの空白の並びは 1 つの半角の空白にし、両端の空白を除いて整える。ひらがなと長音符の並びを空白で区切ったものでなければ、その人物は使わない。
- 読みの取れた人物を、`build/additional/person/wikipedia-people.tsv` に、Wikidata の人物と同じ列（項目・読み仮名・ラベル・サイトリンク数・日本語版ウィキペディアの記事・生年）で書き出す。読み仮名は取った読み、ラベルは末尾の括弧の添え書きを除いて整えた見出しとする。行は文字列の順に並べる。

人名の辞書は、`wikipedia-people.tsv` があれば、その人物を `people.tsv` の人物と同じく読み、`people.tsv` にない項目の人物を足す。足した人物にも、ここから後の決まりをすべて当てる。そのとき、辞書の素材に `wikidata-people-unread` と `wikipedia-ja` を加える。

### 姓と名

- 区切った読みが 2 つなら姓と名、3 つで真ん中が の なら、の を挟んだ姓と名とする。
- ラベルの頭の字の並びのうち、姓の読みを当てはめられるところで切る。そうした切れ目が複数あれば、残りに名の読みも当てはまる最初の切れ目を、なければ最も長い姓になる切れ目を取る。前を姓の表記、残りを名の表記とする。
- 当てはめは、Mozc の単漢字の表（基本辞書の漢字一字の読みと同じ表）の読みと、その最初のかなを濁らせた形・半濁らせた形、終わりの つ・ち・く・き を っ にした形で行う。`々` は前の字の読み、`ヶ`・`ヵ`・`ケ`・`カ` は か・が・け・こ、ひらがなとカタカナはそのかな（ひらがな）。
- 姓の読みを当てはめられる頭がない人物は使わない。
- 読みが 1 つ（空白がない）なら、ラベル全体に当てはめられるときだけ、姓と名に分けずにフルネームとして使う。

### 項目とコスト

- フルネーム：（姓の読み＋名の読み, ラベル）。読み仮名が の を挟むときと、姓が `additional/person/uji.txt` の氏で生年が 1600 年より前のときは、（姓の読み＋の＋名の読み, ラベル）も入れる。
- フルネームのコストは、その人物の重み（サイトリンク数、0 なら 1。日本語版の記事があれば 2 倍）から `cost_of(重み, フルネームの重みの総和)` で決める。同じ（読み, 表記）が複数の人物から来るときは、重みの大きいほうを使う。
- 姓・名：（姓の読み, 姓の表記）と（名の読み, 名の表記）。表記に漢字を含み、2 人以上の人物が持つものだけにする。コストは `cost_of(持つ人物の数, 姓と名に分けたかフルネームとして使った人物の数)`。

`additional/person/uji.txt` は 1 行に 1 つの氏を書く。`#` で始まる行と空行は読まない。

## 駅名の辞書

駅名の辞書（`station`）は、Wikidata の日本の鉄道駅の読み仮名から作る。どう決めるかは [駅名は Wikidata の読み仮名から取り、駅名の追加辞書にする](../adr/20261012-take-station-names-from-wikidata-into-their-own-dictionary.md) による。

`just additional-fetch` は、QLever（`https://qlever.dev/api/wikidata`）に、鉄道駅（P31 が Q55488 かその下位クラス）で国（P17）が日本（Q17）で読み仮名（P1814）を持つ項目の 項目・読み仮名・日本語のラベル・サイトリンク数を問い合わせ、結果の TSV を `build/additional/raw` に取る。QLever の索引は更新されるので、取り直しを指定するまで取り直さない。`just additional-docs` は、それを `build/additional/station/stations.tsv` に書き出す。

- 1 つの項目の行をまとめて 1 つの駅とする。読み仮名はすべて、サイトリンク数は最も大きいものを使う。
- ラベルは、末尾の括弧の添え書きを除く（三条駅 (京都府) は 三条駅）。漢字を含まないラベルと、かな・漢字・`々`・`ヶ`・長音符のほかの字を含むラベルの駅は使わない。
- 読み仮名は、空白・`・`・ゼロ幅の空白を除き、カタカナをひらがなに、ゐ・ゑ を い・え にする。かな以外の文字が残る読み仮名は使わない。
- ラベルが `駅` で終わり、読み仮名が えき で終わらなければ、読み仮名の後に えき を足す（出町柳駅 でまちやなぎ は でまちやなぎえき）。

### 項目とコスト

- 駅名：（読み仮名, ラベル）。
- 駅を除いた名：ラベルが `駅` で終わり読み仮名が えき で終わるとき、両方から除いた（読み, 表記）も入れる（でまちやなぎ 出町柳）。除いた読みが空のときと、除いた表記が漢字を含まないときは入れない。
- 駅の重みは、サイトリンク数（0 なら 1）。（読み, 表記）の重みは、それを出す駅の重みの和。同じ駅が同じ（読み, 表記）を 2 度出しても 1 度と数える。
- コストは `cost_of(（読み, 表記）の重み, すべての（読み, 表記）の重みの和)`。
