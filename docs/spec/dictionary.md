# 辞書の項目

基本辞書に何が入るか。辞書は Kanaemi の [テキストの辞書](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/text-dictionary.md) の形で書き、活用型の名前は Kanaemi の [活用表](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/conjugation.md) に従う。

## 項目

集めた文章を解析して出てきた語と、UniDic の語から作る。どの語を入れるかは [Sudachi で読み、その語彙一覧は写さない](../adr/20261003-read-with-sudachi-without-copying-its-lexicon.md) による。文章から作れない漢字一字の読みは、他の一覧から取る（漢字一字の読みの節）。

SudachiDict full の語彙のうち UniDic にない部分は core_lex.csv と notcore_lex.csv で、以下 語彙全体 は、UniDic とこの 2 つの人名でない語を合わせたもの。文章に 2 回以上出た表記には、この 2 つの固有名詞でない語がその表記に付ける読みの行も入れる。複合語の切れ端の表記（[複合語](#複合語)）は、複合語の外に出た回数で数える。訂正の語の表記には、訂正の語と違う読みの行は入れない（一回 に いちかい を入れない）。コストは、文章に出た UniDic の語と同じに決める。解析器は品詞が同じ同形異音語を文脈によらず一方の読みで読む（大文字 を だいもんじ）ので、もう一方の読み（おおもじ）は文章から作れない。どう決めるかは [文章に出た語を、SudachiDict の語彙全体の読みでも読む](../adr/20261011-read-the-text-s-words-as-the-whole-sudachidict-lexicon-reads-them.md) による。

| 項目 | 例 |
| --- | --- |
| 活用する語の語幹と活用型 | `か	書	五段-カ行` |
| する の前の語の、サ行変格の語幹 | `かんけい	関係	サ行変格` |
| 文章に実際に出た活用形を、活用しない語として | `かいた	書いた` |
| 活用しない語 | `きしゃ	記者` |
| 複合語 | `へいあんじだい	平安時代` |
| 記事の見出しと語の組 | `たしゅたよう	多種多様` |
| 送り仮名付きの語の行 | `か*く	書く` |
| 助詞を送り仮名とする語の行 | `き*に	気に` |
| だ を送り仮名とする形容動詞の行 | `せんさい*な	繊細な` |
| 数値の項目 | `{}ほん	{half-num}本`、`だい{}かい	第{kanji}回` |
| 漢字一字の読み | `すで	既` |

- 送り仮名付きの語の行は、表記が漢字とひらがなで終わる語（書く、皆さん、明らか）から作る。表記の最後の漢字より後ろのひらがなを送り仮名とし、送り仮名を指定して打ったときにも引けるようにする。漢字が 1 字の行で、もとになった語のコストがどれも、文書に 2 回出た語のコスト以上のもの（祈とう の き*と 祈と、気っぷ の き*っ 気っ）は作らない。どう決めるかは [まれな一字の交ぜ書きからは、送り仮名付きの語の行を作らない](../adr/20261008-leave-rare-one-kanji-fragments-out-of-okurigana-lines.md) による。そのまま打つ語（活用しない語で、活用形が数えたものでないもの。長さ、来て）だけから作る行は、もとの語のコストに足切りの回数の語のコストを足し、送り仮名を指定して打たれる語（流さ、着て）より後ろに並べる。どう決めるかは [そのまま打つ語の送り仮名付きの行は、送り仮名を指定して打つ語より後ろに並べる](../adr/20261012-rank-okurigana-lines-of-words-typed-whole-behind-the-forms-typed-marked.md) による。
- 助詞を送り仮名とする語の行は、表記が漢字で終わる活用しない語と、解析器がそのすぐ後ろに読んだ、ひらがなで書かれた助詞の組から作る。助詞の最初のかなを送り仮名とし（気 と に から き*に 気に）、送り仮名を指定して打ったときにも引けるようにする。組が 10 回以上出たものを入れる。コストは組の数から決めたものに 400 を足し、同じ読みで送り仮名を指定して打たれる活用する語の形（め*で の 愛で）を先に並べる。送り仮名付きの語の行にも同じ行があれば、小さいほうのコストを取る。どう決めるかは [助詞の前の語は、助詞を送り仮名として指定して打っても引けるようにする](../adr/20261024-look-up-a-word-before-a-particle-typed-with-the-particle-as-okurigana.md) による。
- 解析器が、表記が漢字で終わる活用しない語のすぐ後ろに する（サ行変格）を読んだとき（関係 と した）、その語をサ行変格の語幹としても数える（`かんけい	関係	サ行変格`）。語幹と同じく、2 回以上出たものを入れる。Kanaemi が する を活用させるので、送り仮名を指定して打っても（かんけい*す、かんけい*し、かんけい*さ）、そのまま打っても（かんけいした）引ける。語そのもの（`かんけい	関係`）は今までどおり数える。
- だ を送り仮名とする形容動詞の行は、表記が漢字で終わる形容動詞の語（解析器が 形状詞 か、形状詞にもなる名詞と読むもの。繊細、有利）と、解析器がそのすぐ後ろに読んだ だ の形（だ、な、に、で、だっ、なら）の組から作る。最初のかなを送り仮名とし（繊細 と な から せんさい*な 繊細な）、組が 2 回以上出たものを入れる。コストは助詞を送り仮名とする語の行と同じく、組の数から決めたものに 400 を足す。ほかの名詞の後ろの だ（学生だ）は語をつなぐだけなので、行を作らない。Kanaemi の活用表は だ を持たないので、語幹の行にはしない。
- サ行変格の語幹と だ を送り仮名とする行をどう決めるかは [サ変動詞と形容動詞の語幹は、送り仮名を指定して打っても引けるようにする](../adr/20261024-look-up-suru-verbs-and-adjectival-nouns-typed-with-okurigana.md) による。
- 活用表が扱わない語（来る、単独の する、いい）は、それぞれの形を活用しない語として入れる。
- 活用表が知らない活用型（文語形容詞-ク、文語助動詞-ゴトシ など）の語は、語幹を作らない。その形は、活用表が扱わない語と同じく、活用しない語として入れる（如く、若き、思ふ）。表記が漢字だけの形（深掘り の 深 を こし と読んだもの）は、ほとんどが読み違いなので、単位からは数えない。表記の最後の漢字の後にひらがなが続き、その分を読みの終わりに持つ形だけ数える。UniDic や語彙全体が活用しない語として持つ行（そうろう 候）は、ほかの語と同じに入る。どう決めるかは [活用表が知らない活用型の語の形は、活用しない語として入れる](../adr/20261012-enter-forms-of-conjugation-types-the-table-does-not-know-as-words.md) による。
- 送り仮名を省いて書いた活用形（有、立）と、形容詞のウ音便（早う）からは、活用する語の語幹を作らない。送り仮名のない形の動詞の語幹（漢字で終わるもの）が、表記の文字の数より多いかなで読まれるとき（補 を おぎなえ）も、送り仮名を省いた形とする。見＝み、出来＝でき のような語幹はそのまま作る。形容詞の語幹は送り仮名なしで使う（浅すぎる の 浅）ので、そのまま作る。ウ音便の形は活用しない語として入れる。送り仮名を省いた形は、その表記と読みの組を UniDic が活用しない語として持つときだけ入れる。漢字だけの表記を解析器が活用形と読んだもの（補 を おぎなえ）は、ほとんどが読み違いのため。
- 括弧で読みを添えた表記（明日（あした））は語ではないので入れない。
- 読みが促音で終わる活用形（知らなかっ、ハマっ）と、読みが促音で終わり表記に漢字のある語は、活用形が途中で切れたものなので入れない。語幹の項目があれば、その語はそこから引ける。
- 次の表記は、語の一部や文字の崩れなので入れない。基本辞書にも追加辞書にも当てる。
  - 読みが促音・撥音・長音・小書きのかなで始まるもの（ッて、ンな、っ放し）
  - 解析器が記号として読むもの（☆彡）
  - 空白、文字から離れた濁点・半濁点、読点を含むもの（美 少年、ヘ゛ヒ゛ー、一、二塁間）
  - ハイフンや波ダッシュで終わるもの（インター-、カーポーカー〜）

## 区切りと読み

語の区切りと読みは、解析器が文章に付けたものによる。解析器の読みの確かめ方と直し方は [解析器の読みを確かめ、誤りを直す](../adr/20261006-check-the-analyzer-s-readings-and-correct-them.md) による。

- 接頭辞は後ろの名詞・形状詞と、接尾辞は前の名詞・代名詞とひとまとまりにする（大相撲、山田さん）。動詞・形容詞には接頭辞をつながない。つないだ語が語彙（UniDic と SudachiDict の語彙全体）にないときは、単位に、その中の変換の要る語（山田さん の 山田）と位置を持たせる。途中までつないだ語が語彙にあれば（大御所的 の 大御所）、それを 1 語とする。そうした単位のうち、同じ読みと表記の単位が辞書の足切りの回数以上、数える文書の複合語の外に出るものは定着した語として 1 語で数えて打ち、それより少ないものは、辞書がその中の語として数え、並べ替えのモデルの学習と素材の文書での評価もその中の語に分けて打つ。語の組と記事の見出しの読みは、つないだ単位の並びで見る。どう決めるかは [接辞をつないだ語で、語彙になく文書にもまれなものは、その中の語として数える](../adr/20261012-count-affixed-words-no-lexicon-has-as-their-parts.md) による。
- 動詞の連用形、形容詞の語幹、形状詞の直後の、動詞（非自立可能）と接尾辞（形容詞的・動詞的）は、前の語とひとまとまりの活用する語にする（多すぎる、読みやすい、寒がる、書き始める）。活用型は後ろの語のもの。前の語の直前に お・ご・御 が続くとき（お願いします、お選びください）と、後ろの語が する・いたす・くださる・いただく（いただける）のとき（敬語の型）はつながない。複合語と同じく、部分の語とは別に数え、素材の文書での評価と並べ替えのモデルの学習では複合語と同じに扱う。どう決めるかは [補助的な動詞と接尾辞は、前の語とつないで 1 つの活用する語にする](../adr/20261007-join-auxiliary-verbs-and-suffixes-to-the-word-before.md) による。
- ひとまとまりにした語の表記が語彙全体にあり、つないだ読みが語彙全体の読みのどれとも合わなければ、語彙全体の読みにする（大掃除 は だいそうじ でなく おおそうじ）。語彙全体の読みのうち、つないだ読みと語のつなぎ目のかなの濁りだけが違うものがあればそれを、なければ語彙全体の読みが 1 つのときはそれを使う。ただし 1 つの読みが、前の語の読みで始まらず、後ろの語の読み（最初のかなの濁りは問わない）で終わりもしないときは、同じ表記の別の語の読みとして、つないだ読みのままにする（下山中 は 地名の しもやまなか でなく げざんちゅう）。語彙全体の読みが 2 つ以上あってどれでもなければ、ひとまとまりにしない。
- 活用しない語の読みが、その表記の UniDic の読みのどれとも合わなければ、同じ文を SudachiDict small で読んだときに同じ位置・同じ表記の語に付く読みにする。その読みも UniDic になければ、解析器の読みのままにする。
- カタカナだけの表記の読みは、表記をひらがなにしたものにする（ヰ・ヱ は い・え）。漢字の代わりに使う ヵ・ヶ（3ヶ月）と、ひらがなのない ヷ・ヸ・ヹ・ヺ を含む表記は除く。解析器は書き方の揺れたカタカナ語に、ふつうの書き方の語の読みを付けるため（ランウェイ を らんうえい、キターーー を きたー と読む）。
- 解析器が誤って読む語や区切る語は、訂正の語として `analyzer/corrections.tsv` に書き、解析器の区切りに当てる。語でないのに辞書に入る表記は、外す語として同じ表に書き、辞書に入れない。
- 表記に 日本 を含む活用しない語で、読みに にほん を含む項目が 1 つもなく、読みが にっぽん を含むもの（にっぽん の数が 日本 の数より多いものを除く）は、読みの にっぽん をすべて にほん にした項目も、同じコストで入れる。解析器は長い語の中の 日本 を多く にっぽん と読む（日本時間 を にっぽんじかん）が、その多くは にほん で打たれる。日本銀行 のように正しく にっぽん と読む語もあるので、置き換えずに足す。文書から作る分野の辞書も同じ。どう決めるかは [にっぽん とだけ読む 日本 の語に、にほん の読みを足す](../adr/20261008-add-nihon-readings-to-words-read-nippon.md) による。

### 複合語

文章は C 単位で切り、それを B 単位に分ける。上の区切りと読みは B 単位のもの。どう決めるかは [解析器がまとめる複合語も語として数える](../adr/20261007-count-compound-words-as-the-analyzer-groups-them.md)、[数を含む複合語も、数値の項目で表せないものは語として数える](../adr/20261007-count-compounds-that-hold-a-numeral-as-words.md)、[ほとんど複合語の中にしか出ない語は、複合語の外に出た回数で数える](../adr/20261011-count-words-seen-mostly-inside-compounds-only-outside-them.md) による。

- 2 つ以上の B 単位をまとめた C 単位のうち、名詞のものを、複合語として活用しない語の項目にする。読みは解析器が C 単位に付けたもの。数詞を含むもの（日本一、第一次世界大戦、一眼レフ）も、読みに数を置き場所にせず、そのまま項目にする。
- B 単位が、数値の項目のまとまり（接頭辞、数、助数詞、その後ろの接尾辞）と、助数詞の付かない数だけでできている C 単位（第一子、三回忌、二階建て）は、数値の項目で表せるので、複合語にしない。
- 複合語の足切りは、ほかの語と同じ。B 単位の語と同じ表記・読みなら、同じ項目として数える。
- 活用しない B 単位の語のうち、表記が出たところ（読みを問わない）の 3/4 以上が同じ位置の複合語の中にあるもの（危機一髪 の 一髪）は、複合語の外に出た回数だけを数える。数値の単位と活用する語には当てない。
- C 単位の中の、先頭でない名詞の B 単位で、読みの最初のかなが濁り、その読みの最初のかなを濁らない形にした読みを UniDic がその表記に持つときは、その読みにする（露天風呂 の 風呂 は ふろ）。
- 訂正の語は、表記が同じ複合語の読みを替える。外す語の表記の複合語は書かない。
- 素材の文書での評価は、解析器がまとめる複合語を 1 回で打つ。打つ単位の決め方は [評価](evaluation.md#打つ単位) に書く。
- 並べ替えのモデルの学習は、複合語を使わず、B 単位の語だけで行う。

### 送り仮名の揺れ

活用する語のうち、終止形と解析器の正規化した形とで、読みと漢字が同じで送り仮名だけが違うもの（小い、行なう、取組む）は、送り仮名の揺れとして基本辞書に入れない。素材の語の総数には数える。どう決めるかは [送り仮名の揺れは基本辞書に入れず、別の追加辞書にする](../adr/20261007-keep-okurigana-variants-in-their-own-dictionary.md) による。送り仮名の揺れは、追加辞書の送り仮名の揺れの辞書（[追加辞書](additional.md)）に入る。

### 記事の見出し

基本辞書は、Wikipedia の記事の見出しと、記事とリダイレクトの見出しにある語の組を取る。どう決めるかは [Wikipedia の記事とリダイレクトの見出しにある語を、基本辞書に入れる](../adr/20261007-take-words-named-by-wikipedia-titles-and-redirects.md) による。

- 記事（曖昧さ回避を除く）の見出しを、記事の冒頭の読みとともに取る。カテゴリでは絞らない。冒頭に読みのない記事と、半角・全角の数字を含む見出しは取らない。
- 見出しが基本辞書の文書に出る回数を数える。どう数えるかは [見出しは、文書で見出しと同じ読みの語として出た回数で数える](../adr/20261007-count-titles-by-units-read-as-the-title.md) による。
  - 漢字とカタカナ（長音符を含む）だけの見出しは、文書の区切りのどこに表記が出るかで数える。1 つの区切りが表記と同じところは、その読みが見出しの読みと同じときだけ数える。隣り合う 2 つ以上の区切りをつないで表記になるところは数える。長い区切りの中（お菓子 の 菓子）と、前後に漢字かカタカナで終わる・始まる区切りが続くところ（東京都庁 の 東京）は、長い語の一部なので数えない。複合語は見ない。
  - ひらがなを含む見出しは、表記が文書に語として出る回数を数える。前後が漢字、カタカナ、英数字で続くものは、長い語の一部なので数えない。
- 2 回以上出た見出しを、活用しない語として入れる。コストは出た回数から決める。文書から数えた同じ項目があれば、コストの小さいほうにする。

### 語の組

解析器が分け、C 単位でもまとまらない語（多種／多様、既読／無視）を、隣り合う語の組から取る。

- 文書の中で隙間なく隣り合う 2 つか 3 つの語で、どの語も漢字かカタカナ（長音符を含む）だけで書かれたものを、語の組とする。複合語は組に使わない。
- 数値の項目を含む組は、最後の語が数値の項目でないものだけにする（二次会 は入れ、一月一日、平成十六年 は入れない）。どう決めるかは [数値の項目の後ろに語が続く組も、語の組として取る](../adr/20261007-take-word-chains-that-hold-a-numeric-unit.md) による。
- 組の表記が、Wikipedia の記事かリダイレクトの見出し（括弧の添え書きを除く）と同じで、組が 5 回以上出て、記事の見出しを足した後の基本辞書にその表記の項目がないものを候補にする。
- 候補の表記が文書に出たところの、すぐ前の文字とすぐ後ろの文字を数える。前と後ろのそれぞれで、漢字・カタカナ・長音符でない文字の割合が半分以上で、文字の散らばり（エントロピー）が 1.5 ビット以上のものを残す。
- 読みは、その組で最も多く出た部分の読みをつないだもの。数値の項目の読みは、そのかなの読み（数値の項目の節）。つなぎ目では、後ろの部分の最初のかなを、解析器の複合語で多いほうに合わせて濁らせるか半濁らせ、前の部分の最後の つ・ち・く・き を、多いほうに合わせて っ にする。
  - 解析器の複合語から、部分の表記と読みごとに、次の部分の頭の変わり方（変わらない・濁る・半濁る）と、前の部分の終わりの変わり方（変わらない・っ になる）を数える。複合語は、表記・読み・部分の組ごとに 1 回と数える。2 回以上数えたものだけを使う。
- 残った候補は記事の見出しと同じく、語として 2 回以上出たときに活用しない語として入れ、コストは出た回数から決める。

### 訂正の語

`analyzer/corrections.tsv` は 1 行に 1 語を、表記と読み（ひらがな）のタブ区切りで書く（`深掘り	ふかぼり`）。読みを `-` にした行は外す語（`十つ	-`）。`#` で始まる行と空行は読まない。

- 解析器の続いた区切りの表記をつないだものが訂正の語の表記と同じなら、それを 1 つの普通名詞にまとめ、読みを訂正の語の読みにする。1 つの区切りの表記と同じなら、その読みだけを替える。
- 重なって当たるときは、前から順に、より長い訂正の語を当てる。
- 解析器が 2 つ以上に分けた数の途中からは当てない（二十＋三＋分 の 三分 には当てない）。
- 訂正の語は、UniDic での読みの確かめより後に当てる。
- 外す語の表記の項目は、読みによらず、基本辞書にも追加辞書にも書かない。解析器の区切りには当てない。
- 訂正の語は、解析器や読みの確かめ方が変わると要らなくなるので、見直す前提で置く。足したとき、また解析器や読みの確かめ方を変えたときは、`just check-corrections`（[辞書の確かめ](checks.md#訂正の語の見直し)）で要らない行を探して外す。

## 数値の項目

数を含む語は、Kanaemi の [数値変換](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/numeric-conversion.md) の置き場所で書く。どの語をどう書くかは [数を含む語は、文章での書き方を数えて数値の項目にする](../adr/20261005-count-numeric-items-by-how-the-text-writes-them.md) による。

- 数と、その直後の助数詞・接尾辞、数の前の接頭辞をひとまとまりにする。
- 助数詞の後ろの 位 は くらい と読む（3歳位）。数の直後の 位 は順位として い と読む（3位）。解析器はどちらも い と読むため。
- 表記の置き場所は、文章での数の書き方を書く Kanaemi の組み込みの関数の名前で書く（`3` は `{half-num}`、`３` は `{wide-num}`、`三` は `{kanji}`、`二〇二六` は `{kanji-num}`、`1,000` は `{grouped-num}`、`壱` は `{daiji}`）。名前のない `{}` は打ったままの数を返し、全角で打てば全角になるので使わない。
- 置き場所の後ろの読みの最初のかなが は行（濁った形・半濁った形を含む）なら、そのかなの濁らない形・濁らせた形・半濁らせた形の行もすべて書く（`{}ほん`・`{}ぼん`・`{}ぽん` → `{half-num}本`）。ほかの行のかなでは書かない（`{}かい	{half-num}回` に `{}がい` の行はない）。どう決めるかは [数値の項目の濁った読みは、濁る助数詞にだけ足す](../adr/20261012-voice-numeric-items-only-where-the-counter-voices.md) による。
- 一から十までの漢数字と助数詞の語（[小さい数の語](#小さい数の語)の節の語と、文書から入った同じ形の語）の読みで、助数詞の読みの最初のかなが濁っているもの（訂正の語の 三階＝さんがい、三軒＝さんげん）があれば、その助数詞の数値の項目のどの表記にも、その濁らせた読みの行を、濁らない読みの行と同じコストで書く（`{}がい` → `{half-num}階`・`{kanji}階`）。前に接頭辞が付く項目（`やく{}げん` → `約{half-num}軒`）と、助数詞の後ろに語が続く項目（`{}げんあたり` → `{kanji}軒当たり`）にも書く。濁らない読みの行からだけ作り、濁った読みの行から濁らない形は作らない（`{}だん	{half-num}段` から `{}たん` は作らない）。
- 数だけの項目は書かない。打った読みをそのまま返す項目（`3` と、打ったとおりのかなの `3つ`）も書かない。
- 表記に括弧を含む項目（`{half-num}日（アスキー）`）は、括弧で添え書きをした語なので書かない。
- 数値の項目の単位には、語の組の読みに使うかなの読みも持たせる。数の読みと助数詞の読みをつなぎ、小さい数の語と同じく、助数詞は UniDic が助数詞として読む濁らない読みから始め、数の読みの終わりが ん なら 三、じゅう なら 十、ひゃく（びゃく、ぴゃく）なら 六、いち・ろく・はち ならそれぞれの数の後と同じ規則で変える（一発＝いっぱつ、二十一本＝にじゅういっぽん）。
- 素材の文書での評価と並べ替えのモデルの学習は、Kanaemi の組み込みの関数で置き場所を埋める。利用者が足す関数は使わない。

### 数を書かない数詞

解析器が数詞として返すもののうち、漢字だけで書かれ、数を書く漢字（〇一二三四五六七八九十百千万萬億兆京壱弐参拾廿卅零）でない漢字を含むもの（数年 の 数、何倍 の 何、幾日 の 幾、数百人 の 数百）は、いくつと言わずに数える語で、数値の項目にしない。どう決めるかは [数を書かない数詞（数・何・幾）は、続く助数詞とつないで語にする](../adr/20261007-make-words-of-numerals-that-write-no-number.md) による。

- 数値の項目と同じまとまり（数の前の接頭辞、数詞、助数詞、助数詞の後ろの接尾辞）を、活用しない語にする（数年、何倍、数日後、数千万人）。助数詞が続かなければ、数詞だけを語にする。
- 読みは解析器の読みをつないだもの。ただし助数詞の読みは、数値の項目のかなの読みと同じ規則で変える（何匹＝なんびき、数十本＝すうじゅっぽん、数百回＝すうひゃっかい）。ほかの読み（すう、いく）の後では変えない（数本＝すうほん）。
- 表記を語彙全体（[項目](#項目)の節）が持ち、そうして決めた読みが語彙全体の読みのどれとも合わなければ、語彙全体の読みのうち数詞と助数詞のつなぎ目のかなの濁りだけが違うもの、なければ語彙全体の読みが 1 つのときはそれにする。どちらでもなければ語にしない。規則と変わり方の違う語（何階＝なんがい）は、訂正の語で直す。
- それ以外の数詞（3万、1.5、①、ゼロ、十二三、廿）の隣の接頭辞と助数詞は、数値の項目ができなくても単独の語にしない（第3の の 第、3万円 の 円）。

### 小さい数の語

数値の項目の助数詞ごとに、一から十までの漢数字と組にした語（一匹〜十匹）を、活用しない語として書く。どう決めるかは [小さい数と助数詞の語を、かなの数で打っても引けるようにする](../adr/20261006-make-small-counted-words-typed-with-kana-numbers.md) と [小さい数の語のコストを、その表記が書かれた回数でも決める](../adr/20261011-cost-small-counted-words-also-by-how-often-they-are-written.md) による。

- 助数詞は、置き場所で始まり、置き場所がほかにない数値の項目の、置き場所より後ろの表記のうち、漢字かかなで始まり、括弧を含まないもの（`{half-num}mm` の mm、`{half-num}日（セル）` の 日（セル） は助数詞にしない）。
- 読みは、語を解析器で読んで決める。先頭が普通名詞なら、その読みに後ろの読みをつないだもの（九時間 は 九時＋間）。先頭が数で、その読みが和語なら、数と助数詞の読みをつないだもの。漢語なら、次の規則で変えたもの。どれでもなければ書かない。
- 規則を当てる助数詞の読みは、助数詞の表記を UniDic が助数詞（接尾辞、助数詞、助数詞可能）として読む読みのうち、解析器の読みの最初のかなを濁らない形にしたもの（杯＝はい）。それがなければ解析器の読みそのもの（倍＝ばい）、それもなければ UniDic の読みが 1 つのときはその読み（話＝わ）。どれでもなければ解析器の読み。
- コストは、その助数詞の数値の項目のうち最も小さいコストに、十の数から 1 つを選ぶ分を足したもの。ただし、同じ表記の数値の単位が文書に 2 回以上書かれていれば（一発）、その回数から決めたコストのほうが小さいときはそれにする。

| 助数詞の最初の音 | 変わる数 | 例 |
| --- | --- | --- |
| か行 | いち・ろく・はち・じゅう は促音 | いっこ、ろっこ、はっこ、じゅっこ |
| さ行・た行 | いち・はち・じゅう は促音 | いっさつ、はっさつ、じゅったく |
| は行 | いち・ろく・はち・じゅう は促音にして半濁る。さん は濁る | いっぴき、ろっぽん、はっぴき、じゅっぽん、さんぼん |
| ほか | 変わらない | にまい、さんまい |

数ごとに読みは 1 つだけ作る。助数詞によって変わり方の違う語（三階＝さんがい、三分＝さんぷん）は、訂正の語で直す。

## 漢字一字の読み

漢字一字の読み（`すで	既`）を、活用しない語として基本辞書に書く。どう決めるかは [漢字一字の読みは Mozc の単漢字の一覧から取り、語より後ろに並べて基本辞書に入れる](../adr/20261007-take-single-kanji-readings-from-mozc-and-unihan.md) による。

- 読みと字の組は、Mozc の単漢字の表（commit を固定する）の 1 行 `読み<TAB>字の並び` を、字ごとに分けたもの。
- 基本辞書の語に出る漢字のうち Mozc の表にない字は、Unihan（版を固定する）の `kJapanese` のカタカナの読みをひらがなにして足す。
- `kanji/excluded.tsv` は 1 行に `読み<TAB>字` の組を書き、その組を入れない。`#` で始まる行と空行は読まない。
- 同じ（読み, 表記）の活用しない語が基本辞書にあれば、その組は書かない。
- 組の裏付けは、基本辞書の活用しない語（送り仮名付きの語の行を除き、表記が漢字とかなだけのもの）から取る。語の読みを、表記の字ごとに組の読みかかな自身で当てはめ、語の回数を当てはめた組に配る。当てはめ方が複数あれば等分する。
- コストは、裏付けのある組は `4096` に配られた回数から決めたコストを足したもの（8191 で止める）。裏付けのない組は `8192` に、その字が基本辞書の語に出た回数から決めたコストを足したもの。

## コスト

どの行にもコストを書く。コストは、文章でよく出る語ほど小さい。UniDic にだけあって文章に出てこない語は、文章に出た語より後ろに並ぶコストにする。漢字一字の読みは、どの語より後ろに並ぶ（漢字一字の読みの節）。

語幹と活用型を持つ活用形を活用しない語とした行（`かく	書く`）は、送り仮名を指定せずにそのまま打ったときのためにある。活用表が扱わない語の形（来ました）は、もとから活用しない語として打つので、ふつうの語と同じに数える。活用形は送り仮名を指定して打つ（か*く）ので、この行のコストは、同じ読みと表記の活用しない語の単位（名詞の 笑い）だけの回数で決める。その単位が辞書の足切りの回数に満たなければ、活用形とその単位を合わせた回数から決めたコストに、足切りの回数の語のコストを足し、その読みで文章に足切りの回数以上出たどの語（かく の 各）より後ろに並べる。記事の見出しや語の組として入る語（追加辞書の見出しの 笑い）は、それらのコストが小さければそちらを使う。送り仮名付きの語の行（`か*く	書く`）は、活用形の回数も合わせたコストのまま。どう決めるかは [活用形をそのまま打つ行は、その読みで打たれる語より後ろに並べる](../adr/20261012-rank-conjugated-forms-typed-whole-behind-the-words-of-their-reading.md) による。

## 説明の行

1 行目は `# Kanaemi 公式辞書・<表示名>（kanaemi-dict）`。基本辞書の表示名は `基本`。

## 活用表の確かめ

活用する語の送り仮名が、Kanaemi の活用表でその型の語幹の後ろに付いてよい読みでも、その始まりでもないときは、辞書を作るたびに（活用型, 送り仮名）と回数、例を報告する。人が見て、解析の誤りか活用表の漏れかを判断し、漏れなら Kanaemi の不具合として直す。

書き出す辞書に Kanaemi が読めない行があれば、辞書を書き換えずに失敗させる。
