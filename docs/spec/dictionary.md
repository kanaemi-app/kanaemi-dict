# 辞書の項目

基本辞書に何が入るか。辞書は Kanaemi の [テキストの辞書](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/text-dictionary.md) の形で書き、活用型の名前は Kanaemi の [活用表](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/conjugation.md) に従う。

## 項目

集めた文章を解析して出てきた語と、UniDic の語から作る。どの語を入れるかは [Sudachi で読み、その語彙一覧は写さない](../adr/20261003-read-with-sudachi-without-copying-its-lexicon.md) による。

| 項目 | 例 |
| --- | --- |
| 活用する語の語幹と活用型 | `か	書	五段-カ行` |
| 文章に実際に出た活用形を、活用しない語として | `かいた	書いた` |
| 活用しない語 | `きしゃ	記者` |
| 送り仮名付きの語の行 | `か*く	書く` |

- 送り仮名付きの語の行は、表記が漢字とひらがなで終わる語（書く、皆さん、明らか）から作る。表記の最後の漢字より後ろのひらがなを送り仮名とし、送り仮名を指定して打ったときにも引けるようにする。
- 活用表が扱わない語（来る、単独の する、いい）は、それぞれの形を活用しない語として入れる。
- 活用表が知らない活用型の語は入れない。
- 括弧で読みを添えた表記（明日（あした））は語ではないので入れない。

## コスト

どの行にもコストを書く。コストは、文章でよく出る語ほど小さい。UniDic にだけあって文章に出てこない語は、文章に出た語より後ろに並ぶコストにする。

## 説明の行

1 行目は `# Kanaemi 公式辞書・<表示名>（kanaemi-dict）`。基本辞書の表示名は `基本`。

## 活用表の確かめ

活用する語の送り仮名が、Kanaemi の活用表でその型の語幹の後ろに付いてよい読みでも、その始まりでもないときは、辞書を作るたびに（活用型, 送り仮名）と回数、例を報告する。人が見て、解析の誤りか活用表の漏れかを判断し、漏れなら Kanaemi の不具合として直す。

書き出す辞書に Kanaemi が読めない行があれば、辞書を書き換えずに失敗させる。
