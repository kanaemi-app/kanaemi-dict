# 辞書の確かめ

作った辞書を、素材の文書での評価とは別の方法で確かめる。素材の文書での評価は、正解の区切りと読みを辞書と同じ解析器から取るので、解析器の誤りは正解にも入って見えない。ここの確かめは、正解や比べる相手を解析器の外から取る。

どれも配布物は変えない。結果は `build/` に書く。

## 正解集

人が書いた正解で、辞書と並べ替えのモデルの組を Kanaemi で変換して測る。正解集は `evaluation/words.tsv` に置く。

1 行に 1 語を、次の 4 列のタブ区切りで書く。`#` で始まる行と空行は読まない。

| 列 | 中身 | 例 |
| --- | --- | --- |
| 分類 | 結果をまとめる単位 | `熟字訓` |
| 前の文 | 語の前に打ってある文。空でもよい | `会議で` |
| 読み | 打つ読み（ひらがな）。送り仮名を指定して打つ語は、送り仮名の最初のかなの前に `*` を置く | `か*い` |
| 正解 | 正しい表記。どれでもよい表記が複数あれば `|` で区切る | `書い` |

- 語ごとに、何も学んでいない Kanaemi に前の文を打ち、読みを変換する。
- 候補は、素材の文書での評価と同じく、変換の結果の後ろに、結果になければ読みのカタカナを足したもの。正解のどれかが最初に出た順位を、その語の順位とする。
- 送り仮名を指定する語は、送り仮名の最初のかなまでを打ち、正解もそこまでの表記で書く（書いた は `か*い` と `書い`）。
- 数は、打つとおりの数字で読みに書く（`3ぼん`）。

正解集の語は、素材や解析器の辞書から写さず、人が書く。正解に迷う語は入れない。

`just check-words` は、`dictionaries/` の基本辞書を、並べ替えのモデルなしとありで変換する。分類ごとの語の数・候補に入った数・最初に出た数・平均順位を `build/check-words.tsv` に、最初に出なかった語を、そのとき最初に出た候補と正解の順位とともに `build/check-words-misses.tsv` に書く。

`just check-words --build` は、作ったばかりの `build/dictionaries/base.tsv` を、モデルなしで変換する。基本辞書を作り直すたびに、モデルを学習し直したり `dictionaries/` に入れたりせずに測るため。モデルは組になる基本辞書で学習し直すまで使えないので、モデルありは測らない。

## 項目の抜き出し

辞書の項目を無作為に抜き出し、人が正誤を判定して、辞書の誤りの割合を見積もる。

`just check-sample` は、`dictionaries/` の辞書の項目を層に分け、層ごとに決まった数を抜き出して `build/check-sample.tsv` に書く。同じ辞書からは何度でも同じ項目を抜き出す。

- 基本辞書の層は、活用する語、数値の項目、UniDic にだけある語（文章に出なかった語のコスト）、文章に出た語をコストで分けたもの。
- 追加辞書は、辞書ごとに 1 つの層。
- 抜き出した行には、層、辞書、読み、表記、活用型、コストと、判定を書く空の列が付く。

判定は、読みと表記の組が、その語として正しく、打って引けて役に立つかを見る。判定の結果と誤りの割合は、日付を付けて [docs/references/](../references/) に残す。

## 別の解析器との食い違い

辞書の読みを、Sudachi や UniDic とは別の系統の解析器（MeCab と IPAdic）の読みと比べ、食い違う項目を並べる。食い違いは誤りそのものではなく、人が見る候補を絞るためのもの。見つけた誤りは訂正の語（[辞書の項目](dictionary.md#訂正の語)）で直す。

`just check-readings` は、`dictionaries/` の辞書の、表記に漢字を含む項目の表記を MeCab で読む。

- 活用する語は、語幹に終止形の語尾を付けた形（書く）を読み、その読みを比べる。
- 数値の項目、送り仮名付きの語の行（元の語の項目を送り仮名の始まりで切ったもの）、数字や空白を含む表記は読まない。MeCab は数字を 1 字ずつ読む（2人 を にじん）。
- MeCab が表記を読む候補の上位のどれかが辞書の読みと同じなら、食い違わない。比べるときは、どちらもカタカナにする。
- MeCab が読みを持たない語（未知語）を含むときは、食い違いとせず、読めなかったものとして数える。

- 食い違った項目には、UniDic がその表記に持つ読みのうち、MeCab の読みの候補にもあるものを、直す読みの案として添える。
- 直す読みの案があり、辞書の読みを UniDic が持たない項目は、誤りの見込みが高いものとする。

辞書ごとの、読んだ項目・食い違わなかった項目・食い違った項目（うち誤りの見込みが高いもの）・読めなかった項目の数を表示する。食い違った項目は `build/check-readings.tsv` に、辞書・読み・表記・活用型・コスト・MeCab の読みの候補・直す読みの案・誤りの見込みが高いかの列で書く。辞書ごとに、誤りの見込みが高いものを先に、それぞれコストの小さい順に並べる。
