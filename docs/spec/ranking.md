# 並べ替えのモデル

基本辞書と組にして配る、Kanaemi の [並べ替えのモデル](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/ranking-model.md)。ファイルは Kanaemi のモデルの形式で書く。

- モデルは、基本辞書の後ろに `additional/` のすべての追加辞書を並べた Kanaemi が出す候補を、集めた文章で実際に使われた表記が先に来るように学習する。基本辞書は学習用の文書だけから作ったもの、追加辞書はそれに対して作ったもの（`build/dictionaries/train/`）。
- 追加辞書の並びは文書ごとに変える。名前の順に並べた追加辞書を、文書 ID のハッシュで決めた数だけ回して並べる。打つ人は追加辞書をどの順にも並べ、モデルは候補が来た辞書の位置も見るので、どの追加辞書もどの位置にもほぼ同じだけ来るようにする。どう決めるかは [並べ替えのモデルは、配る追加辞書を基本辞書の後ろに並べて学習する](../adr/20261024-train-the-ranking-model-with-the-additional-dictionaries-behind-the-base.md) による。
- 文章の単位は、素材の文書での評価と同じく打つ（活用する語は送り仮名の最初のかなまでを指定し、ほかの語はそのまま打つ）。接辞をつないだ語で、語彙になく学習用の文書にもまれなもの（寺島さん）は、その中の語（寺島）に分けて打つ。活用する語は、送り仮名をすべて指定して打つ打ち方（か*いた → 書いた）でも学習する。送り仮名が 1 字だけの語は足さない。送り仮名を指定して打つ活用する語を、そのまま打つ打ち方（かいた → 書いた）では学習しない。その読みでは活用しない語（かく の 各）を打つため。送り仮名の前に漢字がない活用する語（ググった）は、評価と同じくそのまま打つ。数を漢数字で書いた単位は、かなの数で打つ打ち方（二本 → にほん）でも学習する。助詞、する、形容動詞の だ の前の活用しない語の単位で、表記が漢字で終わるものは、その最初のかなを送り仮名として指定する打ち方（気 → き*に → 気に、関係 → かんけい*し → 関係し、繊細 → せんさい*な → 繊細な）でも学習する。確定履歴に入れるのは、単位ごとに 1 回、評価と同じ打ち方の組。どう決めるかは [並べ替えのモデルは、活用する語の形を打つどの打ち方でも学習する](../adr/20261008-train-the-ranking-model-on-every-way-a-form-is-typed.md)、[活用形をそのまま打つ行は、その読みで打たれる語より後ろに並べる](../adr/20261012-rank-conjugated-forms-typed-whole-behind-the-words-of-their-reading.md) 、[並べ替えのモデルは、漢数字の数の語をかなの数で打っても学習する](../adr/20261011-train-the-ranking-model-on-numbers-typed-in-kana.md)、[助詞の前の語は、助詞を送り仮名として指定して打っても引けるようにする](../adr/20261024-look-up-a-word-before-a-particle-typed-with-the-particle-as-okurigana.md) と [サ変動詞と形容動詞の語幹は、送り仮名を指定して打っても引けるようにする](../adr/20261024-look-up-suru-verbs-and-adjectival-nouns-typed-with-okurigana.md) による。
- 辞書の項目で切れ端とした表記（[辞書の項目](dictionary.md) の複合語の節）の B 単位は、複合語の中にあるものを学習に使わない。切れ端は、学習用の辞書と同じ単位から同じ規則で決める。どう決めるかは [ほとんど複合語の中にしか出ない語は、複合語の外に出た回数で数える](../adr/20261011-count-words-seen-mostly-inside-compounds-only-outside-them.md) による。
- モデルは、組にした基本辞書と一緒に使う。基本辞書を作り直したら、モデルも学習し直す。
- 追加辞書は、基本辞書の後ろにどの順で置いても使える。追加辞書を作り直したり足したりしても、モデルを学習し直さずに使えるが、学習で見ていない候補の重みは学習したものより弱い。
