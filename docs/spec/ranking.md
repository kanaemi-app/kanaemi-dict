# 並べ替えのモデル

基本辞書と組にして配る、Kanaemi の [並べ替えのモデル](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/ranking-model.md)。ファイルは Kanaemi のモデルの形式で書く。

- モデルは、基本辞書だけを読ませた Kanaemi が出す候補を、集めた文章で実際に使われた表記が先に来るように学習する。
- 文章の単位は、素材の文書での評価と同じく打つ（活用する語は送り仮名の最初のかなまでを指定し、ほかの語はそのまま打つ）。活用する語は、そのまま打つ打ち方（かいた → 書いた）と、送り仮名をすべて指定して打つ打ち方（か*いた → 書いた）でも学習する。送り仮名が 1 字だけの語は、そのまま打つ打ち方だけを足す。確定履歴に入れるのは、単位ごとに 1 回、評価と同じ打ち方の組。どう決めるかは [並べ替えのモデルは、活用する語の形を打つどの打ち方でも学習する](../adr/20261008-train-the-ranking-model-on-every-way-a-form-is-typed.md) による。
- モデルは、組にした基本辞書と一緒に使う。基本辞書を作り直したら、モデルも学習し直す。
- 追加辞書は、モデルを学習し直さずに、基本辞書の後ろに置いて使える。
