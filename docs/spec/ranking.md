# 並べ替えのモデル

基本辞書と組にして配る、Kanaemi の [並べ替えのモデル](https://github.com/kanaemi-app/kanaemi/blob/main/docs/spec/ranking-model.md)。ファイルは Kanaemi のモデルの形式で書く。

- モデルは、基本辞書だけを読ませた Kanaemi が出す候補を、集めた文章で実際に使われた表記が先に来るように学習する。
- 文章の単位は、素材の文書での評価と同じく打つ（活用する語は送り仮名の最初のかなまでを指定し、ほかの語はそのまま打つ）。接辞をつないだ語で、語彙になく学習用の文書にもまれなもの（寺島さん）は、その中の語（寺島）に分けて打つ。活用する語は、送り仮名をすべて指定して打つ打ち方（か*いた → 書いた）でも学習する。送り仮名が 1 字だけの語は足さない。送り仮名を指定して打つ活用する語を、そのまま打つ打ち方（かいた → 書いた）では学習しない。その読みでは活用しない語（かく の 各）を打つため。送り仮名の前に漢字がない活用する語（ググった）は、評価と同じくそのまま打つ。数を漢数字で書いた単位は、かなの数で打つ打ち方（二本 → にほん）でも学習する。助詞の前の活用しない語の単位で、表記が漢字で終わるものは、助詞の最初のかなを送り仮名として指定する打ち方（気 → き*に → 気に）でも学習する。確定履歴に入れるのは、単位ごとに 1 回、評価と同じ打ち方の組。どう決めるかは [並べ替えのモデルは、活用する語の形を打つどの打ち方でも学習する](../adr/20261008-train-the-ranking-model-on-every-way-a-form-is-typed.md)、[活用形をそのまま打つ行は、その読みで打たれる語より後ろに並べる](../adr/20261012-rank-conjugated-forms-typed-whole-behind-the-words-of-their-reading.md) 、[並べ替えのモデルは、漢数字の数の語をかなの数で打っても学習する](../adr/20261011-train-the-ranking-model-on-numbers-typed-in-kana.md) と [助詞の前の語は、助詞を送り仮名として指定して打っても引けるようにする](../adr/20261024-look-up-a-word-before-a-particle-typed-with-the-particle-as-okurigana.md) による。
- 辞書の項目で切れ端とした表記（[辞書の項目](dictionary.md) の複合語の節）の B 単位は、複合語の中にあるものを学習に使わない。切れ端は、学習用の辞書と同じ単位から同じ規則で決める。どう決めるかは [ほとんど複合語の中にしか出ない語は、複合語の外に出た回数で数える](../adr/20261011-count-words-seen-mostly-inside-compounds-only-outside-them.md) による。
- モデルは、組にした基本辞書と一緒に使う。基本辞書を作り直したら、モデルも学習し直す。
- 追加辞書は、モデルを学習し直さずに、基本辞書の後ろに置いて使える。
