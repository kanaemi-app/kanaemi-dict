# 素材の取得

辞書を作る素材をどう取得するか。素材は [文章は解析にだけ使い、素材のライセンスは問わない](../adr/20261004-read-any-text-for-analysis-only.md) のとおり、語を選び、数え、学習するためにだけ読む。

## 出所 ID

取得した素材には、どこから取ったかを表す出所 ID を付ける。形は `<素材>` か `<素材>:<素材の中の識別子>`。辞書を作るのに使った素材の出所 ID から、配布物に載せる素材の表示を決める。

## 取り直し

- 取得した中身は、取得したままのバイト列で手元に残す。
- 一度取った URL は、取り直さない。途中で止まっても、次の取得は続きから始まる。
- 取り直しを指定したときだけ、取った URL も取り直す。素材の更新を取り込むときに使う。

## 取得の作法

- 一括で配られている素材は、一括で取る。ページを巡回して取るのは、ほかに手段のない素材だけにする。
- User-Agent に、道具の名前とリポジトリの URL を入れる。
- 公開元が求める間隔を空ける。求めがなければ 1 秒以上空ける。
- サイトを巡回するときは、利用規約で取得を禁じていないと確かめ、robots.txt に従う。robots.txt を読めなければ、そのサイトは取らない。
- 失敗したら、間隔を倍にしながら取り直し、決めた回数で諦める。取り直しても変わらない失敗（見つからない、など）は取り直さない。
