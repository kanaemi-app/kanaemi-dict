# 素材の扱いの根拠

素材の文章をどう扱ってよいかを、2026-10-03〜04 に調べた記録。判断は条文と判例の趣旨によるもので、法律の専門家の確認は受けていない。

## 配るもの

配る辞書に入るのは、語の読みと表記の組と、その並び順だけ。素材の本文は配らない。素材の文章は、語を選び、出現を数え、並べ替えを学習するために読む。

素材の一部に第三者の文章が混ざっていても（国会会議録で読み上げられた新聞記事など）、配るものに文章として現れることはなく、影響は語の出現の回数にとどまる。

## 解析のための利用

著作物に表現された思想や感情を自ら享受することを目的としない利用は、著作権法 30 条の 4 により、必要と認められる限度で、著作権者の許諾なく行える。情報解析（多数の著作物から言語の要素を抽出し、比較・分類などを行うこと）はその例に挙がっている。文章を集めて語を数え、並べ替えを学習するのはこれに当たる。素材のライセンスの条件（CC BY-SA の継承、非営利など）は、配るものに文章が入らない限り及ばない。

ただし、著作権者の利益を不当に害する場合は除かれる。情報解析のために作られ、販売されているデータベースを無断で使う場合などで、kanaemi-dict の素材はこれに当たらない。

取得の作法は著作権とは別の問題で、サイトの利用規約と robots.txt に従う。

## 辞書の項目一覧

表記と読みの対応（保険証＝ほけんしょう）は事実で、1 件ずつ見れば著作物ではない。問題になりうるのは、他人の辞書の項目一覧を丸ごと取り込むこと。

- データベースの著作物（著作権法 12 条の 2）：項目の選び方や並べ方に創作性がある場合
- 不法行為（翼システム事件）：創作性がなくても、他人が手間をかけて作ったデータベースを大量にそのまま取り込み、競合する製品として配る場合

どちらも、素材のライセンスや 30 条の 4 とは別の論点として残る。このため、他の IME の辞書（SKK-JISYO、Mozc の辞書）や、NEologd、SudachiDict の語彙一覧を丸ごと取り込むことはしない。

ライセンスで再配布と改変が明記された一覧は、作った側がその利用を認めているので、この論点に当たらない。UniDic の語彙（BSD-3-Clause）や、Mozc の単漢字の表（BSD-3-Clause）がそうで、表示を添えて取り込める。それでも取り込むのは、漢字一字の読みのように文章から作れない語に要るものに限る（[他の辞書の項目一覧は、文章から作れない語に要り、再配布と改変が明記されているときに取り込む](../adr/20261007-take-other-lists-only-for-words-text-cannot-make.md)）。

自分で集めた文章を解析器で読み、実際に出てきた語の読みを使うのは、これとは性質が違う。語を選ぶのは文章で、解析器の辞書は読みを付ける道具にすぎない。

## SudachiDict の中身

SudachiDict の上流のリポジトリの `LEGAL` と `README.md` による。

| 版 | 中身 |
| --- | --- |
| small | UniDic の語彙だけ。UniDic は BSD-3-Clause（著作権表示と免責の保持が条件） |
| core | small ＋ NEologd の一部 |
| full | core ＋ 固有名詞 |

core と full に入る NEologd の一部の由来：

- はてなキーワード一覧の表記と読み
- 日本郵便の郵便番号データ
- 駅名一覧
- 人名データ（Mozc の人名辞書を活用したもの）
- Web からクロールした表記と読みの組

SudachiDict の core と full、NEologd はいずれも Apache-2.0 で、解析結果の利用を制限していない。
