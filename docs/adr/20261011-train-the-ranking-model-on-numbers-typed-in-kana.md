# 並べ替えのモデルは、漢数字の数の語をかなの数で打っても学習する

状態：採用

## 背景

並べ替えのモデルの学習では、数を含む単位を、評価と同じく数を数字で打つ（二本 → `2ほん`）。小さい数の語（一匹〜十匹）は、かなの数で打つための語なのに（`20261006-make-small-counted-words-typed-with-kana-numbers.md`）、かなの数で打って正解になる例が一つもない。

かなの数の読みは、ほかの語と同じ読みになることが多い（にほん の 日本・二本、いっぱつ の 一発・一髪）。モデルは、日本 を打つ例のたびに 二本 を外れの候補として見て、後ろに回すことだけを学ぶ。前の文なしで にほん と打つと、モデルなしは 日本・二本・ニホン の順（コスト 908・1094・1345）なのに、モデルありは 日本・ニホン・二本 だった。活用する語のそのまま打つ形で起きていたこと（`20261008-train-the-ranking-model-on-every-way-a-form-is-typed.md`）と同じ形。

## 決定

- 数を漢数字で書いた単位（表記の置き場所が `{kanji}` のもの）は、数字で打つ打ち方に加えて、単位のかなの読み（二本 の にほん）でも打って学習する。
- 確定履歴に入れるのは、今までどおり数字で打った打ち方の組だけ。
- 数を数字で書いた単位（2本）は、数字で打つ打ち方だけにする。

## 検討した他の案

- 小さい数の語だけを、かなの数で打つ：かなの読みの候補に表記がなければ例にならないので、どの単位をかなの数で打っても、辞書にある語のぶんだけが例になる。小さい数の語に絞る条件は要らない。
- 数字で書いた単位もかなの数で打つ：かなで打って数字の表記を選ぶ人はいない。
- 評価もかなの数で打つ：評価は数値の項目を確かめるために数字で打つ。かなの数で打つ語は正解集の かなの数 で確かめる。

## 結果

- 前の文なしで にほん と打つと、モデルありでも 日本・二本・ニホン の順になる。
- 素材の文書での第一候補（モデルあり）は、確定履歴なしで 89.47 → 89.46、ありで 92.50 → 92.49 と、ほぼ変わらない。この評価は数を数字で打つので、ねらいの変化は測れない。
- 正解集の第一候補（モデルあり）は 383 → 381。外れたのは 自分事（自分ごと が先）と 多すぎる（多過ぎる が先）で、どちらも書き方の揺れの入れ替わり。
