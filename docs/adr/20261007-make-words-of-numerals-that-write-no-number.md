# 数を書かない数詞（数・何・幾）は、続く助数詞とつないで語にする

状態：採用

## 背景

解析器は、数年、何倍、幾日、数百人 の 数・何・幾・数百 を、3 や 三 と同じ数詞として返す。数詞は数値の項目にする（数を含む語は、文章での書き方を数えて数値の項目にする、による）が、これらはいくつと言わずに数えていて、置き場所に入る数がない。数値の項目ができないとき、数の隣の接頭辞と助数詞は単独の語にしないので（第3の の 第、3万円 の 円）、数年 は 年 ごと文章から消えていた。

数年、何年、数日、数回 は文章に何百回も出る、ふだん打つ語である。解析器がひとつの語として読む 何人、何度、数十 は入っていて、数詞と助数詞に分けて読むものだけが入っていなかった。

## 決定

- 数詞のうち、漢字だけで書かれ、数を書く漢字（〇一二三四五六七八九十百千万萬億兆京壱弐参拾廿卅零）でない漢字を含むもの（数、何、幾、数百、十数）を、数を書かない数詞とする。
- 数を書かない数詞に助数詞が続けば、数値の項目と同じまとまり（数の前の接頭辞、数詞、助数詞、助数詞の後ろの接尾辞）を、活用しない語にする（数年、何倍、数日後、数千万人）。助数詞が続かなければ、数詞だけを語にする。
- 読みは、解析器の読みをつないだもの。解析器は助数詞の読みを前の数で変えない（本 は いつも ぽん）ので、助数詞の読みには小さい数の語の音の変化の規則（小さい数と助数詞の語を、かなの数で打っても引けるようにする、による）を当てる。助数詞は UniDic が助数詞として読む濁らない読みから始め、数詞の読みが ん で終われば 三、じゅう で終われば 十、ひゃく（びゃく、ぴゃく）で終われば 六 の後と同じに変える（何匹＝なんびき、数十本＝すうじゅっぽん、数百回＝すうひゃっかい）。すう や いく の後では変えない（数本＝すうほん）。
- その表記を UniDic が持ち、こうして決めた読みが UniDic の読みのどれとも合わなければ、接辞をつないだ語と同じく、UniDic の読みのうち数詞と助数詞のつなぎ目のかなの濁りだけが違うもの、なければ UniDic の読みが 1 つのときはそれにする。どちらでもなければ語にしない。
- 規則と変わり方の違う語（何発＝なんぱつ、何歩＝なんぽ）と解析器の読みの誤り（数百 を すーひゃく）は、規則に例外の表を持たず、訂正の語で直す。

## 検討した他の案

- 数・何・幾 を、数詞でなく普通の名詞として切る：数年 が 数＋年 の 2 語になり、すうねん と打ってひとまとまりで引けない。
- 数・何・幾 にも置き場所を作る（`{}ねん`）：打つ数がないので、Kanaemi の数値の項目の形に合わない。
- 数・何・幾 の語を一覧で持つ：語を文章から選ぶ原則に反する。どの助数詞と組で使われるかは文章が決める。
- 数値の項目にできない数詞をすべて語にする：解析器は ①、ゼロ、ひと（ひとつ の）、十二三、廿 も数詞として返す。記号やかなの数はつないでも語にならず（①回、ゼロひとつ）、およその数や古い書き方の数（十七八、廿二日）は読みの規則が別で、誤った読みで入る。どれも数を書いているので、数値の項目の側で扱うことになる。
- 解析器の読みをつないだままにし、誤りは訂正の語で 1 語ずつ直す：助数詞の音の変化はほとんどの語に要り（何匹、何本、数十本）、漏れたものは誤った読みで入る。規則は小さい数の語ですでに持っている。
- 助数詞の濁らない読みを UniDic のすべての読みから選ぶ：台 を たい とも読むので、数台 が すうたい になる。助数詞としての読みに限る。

## 結果

- 数年、何年、数日、数回、何倍、数人 のような語が、文章に出た回数で基本辞書に入る。
- 数詞と数の続くもの（数十万円、何百人）も、まとめてひとつの語になる。打つときは全体を打つ。
- 素材の文書での評価と並べ替えのモデルの学習でも、これらは打つ語になる。
- 数を書かない数詞の前の接頭辞（約数年 の 約）は、語の一部になる。
- およその数（十二三）、古い書き方の数（廿、卅）、数字に 万 を続けた数（3万円）は、今までどおり語にも数値の項目にもならない。
