# 数の直後の普通名詞は、文書で数とともに定着していれば助数詞として数える

状態：採用

## 背景

数値の項目は、数の直後の語が接尾辞か、品詞の 3 つ目が「助数詞可能」の名詞のときだけ作っていた（`20261005-count-numeric-items-by-how-the-text-writes-them.md`）。解析器の辞書（SudachiDict）では、種類・段階・項目・品目・分野 は「普通名詞,一般」で、解析器は 3種類 を 3＋種類 に分ける。このため基本辞書に `{}しゅるい` の行が 1 つもなく、Kanaemi で 3しゅるい と打っても 3種類 にならなかった。小さい数の語（`20261006-make-small-counted-words-typed-with-kana-numbers.md`）も数値の項目の助数詞から作るので、さんしゅるい の 三種類 もなかった。

数の後ろに名詞が来ても、その名詞が数を数えているとは限らない（3選手、2資格、1私企業）。どの名詞を助数詞として扱うかを、手で並べずに文書から決めたい。

接辞をつないだ語（皆さん、寺島さん）には、すでに同じ形の決め方がある（`20261012-count-affixed-words-no-lexicon-has-as-their-parts.md`）。単位に中の語を持たせ、同じ単位が辞書の足切りの回数以上、文書に出れば 1 語として数えて打ち、少なければ中の語として数えて打つ。

## 決定

- 数の直後の、変換の要る普通名詞（漢字かカタカナを含むもの）も、助数詞と同じく数とひとまとまりにした数値の単位にする（3種類、`{}しゅるい	{half-num}種類`）。名詞の後ろの接尾辞もまとめる。
- その単位には、数を除いた名詞（接尾辞とつないだ語は、その中の語）を、変換の要る語として持たせる。同じ数値の項目（数を置き場所にした読みと表記）の単位が、辞書の足切りの回数（2 回）以上、数える文書の複合語の外に出れば定着した数値の項目として数えて打ち、少なければ名詞だけを数えて打つ。数える文書と打ち方は、接辞をつないだ語と同じ。
- 数を書かない数詞の後ろの普通名詞（何種類）も同じく、語の中の数詞と名詞を持たせ、定着したときだけ 1 語として数える。
- 定着した数値の項目として数えるときも、辞書はその名詞を語としても数える。後ろの助詞・する・だ も名詞に付ける（1失点の の 失点 と 失点の）。素材の文書での評価と並べ替えのモデルの学習は、数値の項目だけを打つ。
- 小さい数の語は、普通名詞を助数詞とする数値の項目のうち、漢数字の表記（`{kanji}種類`）のものからだけ作る。
- 解析器の複合語を数値の項目で表せるか（`20261007-count-compounds-that-hold-a-numeral-as-words.md`）は、普通名詞を助数詞としないで見る。一人称 は今までどおり複合語として数える。

## 検討した他の案

数字は、2026-11-13 に取り直した素材で、仕事の場の文書と単位の連なり（`20261108-add-web-pages-of-the-workplace-to-the-base-text.md`、`20261108-take-chains-many-documents-write.md`）を入れる前の辞書の作り方で測ったもの。素材の文書での評価の第一候補の割合は、学習用の文書だけの辞書で、追加辞書なし。

- 普通名詞を助数詞にし、名詞を語としては数えない：数の後ろに多く出る名詞が、単独で打ったときに同じ読みの語に負けた（しってん で 知ってん が 失点 より先、れんたい で 連帯 が 連隊 より先）。評価の損失はモデルなしで 22,080、決定の形では 22,022。
- 小さい数の語を、どの表記の数値の項目の助数詞からも作る：基本辞書の行が約 3.7 万増え、ファイルは 26.4MB になる。二資格、二敷金、二私企業 のような、かなの数で打たれない語が大半だった。評価の数字は決定の形とほとんど変わらない（モデルありで 92.00%）。漢数字で書かれた名詞だけに絞ると、新しい助数詞 3,711 のうち 1,029 からしか作らず、増える行は約 1.5 万になる。
- 数の後ろに出た割合で名詞を選ぶ（種類 のように、出たところの何割かが数の後ろの名詞だけ）：割合の閾値を新たに決める必要がある。足切りの回数で選ぶと、選手 や 試合 も数値の項目になるが、3選手 も 3しゅるい と同じく数を数字で打って書く語なので、外す理由がない。
- 助数詞にする名詞を手で並べる：語を文書から選ぶ原則に反し、並べた名詞の分しか入らない。
- かなの数を Kanaemi 本体で読む：ふつうの語に数の候補が混ざる（いちご が 1語 にも当たる）として、`20261006-make-small-counted-words-typed-with-kana-numbers.md` で退けている。

## 結果

2026-11-13 に取り直した素材で測った数字。仕事の場の文書と単位の連なりを入れた辞書の作り方を変更前とし、同じ素材から作り直して比べた。

- 3しゅるい で 3種類、3だんかい で 3段階、さんしゅるい で 三種類、にだんかい で 二段階 が第一候補になる（`evaluation/checks.tsv` に足した）。基本辞書には、`{}しゅるい` が `{half-num}`・`{wide-num}`・`{kanji}`・`{grouped-num}` の 4 つの表記で入る。
- 基本辞書は 765,928 行から 790,289 行になり（読みと表記の組で、増えたのは 25,141、うち数値の項目 7,266 と小さい数の語 16,281。減ったのは 770）、ファイルは 27.4MB から 28.3MB になる。追加辞書は合わせて 17.94MB から 18.01MB になる。減った行の多くは、名詞に接尾辞をつないだ語で、数の後ろに多く出ていたもの（曲入り、連敗中、編成計、公演目）。数値の項目（`{}きょくいり	{half-num}曲入り`）の中に入り、語として数える名詞は中の語（曲）に分けるため。
- 素材の文書での評価で、数値の単位として打つ単位は 100,946 から 110,408 に増え、語として打つ単位は 2,123,577 から 2,114,498 に減った。打つ単位が変わったので、数字はそのまま比べられない。
- 第一候補の割合は、モデルなしで 91.05% から 90.99%、モデルありで 92.70% から 92.63%、追加辞書をすべて後ろに置いてモデルありで 92.88% から 92.81% になる。損失は、モデルなしで 22,652 から 23,278、モデルありで −15,820 から −14,953 になる。増えた分の多くは、新しく数値の単位になった所の表記と同音の語の選び方（`{wide-num}人気` と `{half-num}人気`、第{kanji}制作部 と 第{half-num}制作部、`{half-num}便` と `{kanji}品`）で、前は数を打たず名詞だけを打っていた所。
- 正解集（モデルあり）の、文の後ろで第一候補になる語は 540 から 537 になる（904 のうち）。満たされない確かめは、変更前と同じ 9 項目（ななにん、SNS と、連なりの決まりで入らない 構成図 など）。
- 小さい数の語は、三味（しゃみ）、二識（にしき）、二層（にそう）のように、ほかの語の読みに混ざるものもある。コストは助数詞の数値の項目のコストに 230 を足したものなので、多くはよく使われる語より後ろに並ぶ。
