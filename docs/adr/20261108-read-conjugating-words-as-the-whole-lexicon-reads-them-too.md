# 活用する語も、SudachiDict の語彙全体の読みで読む

状態：採用

## 背景

いい と打っても 良い が出なかった。からい で 辛い、だく で 抱く も出なかった。どれも文章によく出る語で、SudachiDict small の語彙ファイル small_lex.csv（UniDic）は 良い を イイ と ヨイ、辛い を カライ と ツライ、抱く を ダク と イダク で持つ。

解析器は品詞が同じ語の間ではコストの小さい語を選ぶので、良い はどこでも よい、辛い は つらい、抱く は いだく と読まれる。少ないほうの読みは文章から作れない。活用しない語では、この読みを語彙ファイルから補っていた。UniDic の語は文章に出なくても入れ、core_lex.csv と notcore_lex.csv の語は、表記が文章に 2 回以上出たときに入れる（大文字 の おおもじ）。

だが、語彙ファイルから語を取る処理は、活用型を持つ行をすべて飛ばしていた。活用する語の行は活用形ごとにあり（良かっ、良けれ）、活用しない語の行のように 1 行を 1 語として入れられないため。このため、活用する語の少ないほうの読みは、どの語彙ファイルからも入らなかった。

活用する語を辞書に入れる形は、語によって違う。Kanaemi が活用する語は、語幹と活用型の行（から 辛 形容詞）で入れる。Kanaemi は語幹から形を作るので、送り仮名を指定して打っても指定せずに打っても引ける。来る や する のように、形によって語幹の読みが変わる語は、活用表で扱わず、形ごとに活用しない語として入れる。

語彙ファイルの活用する語の読みには、使われ方の違う読みも並ぶ。連濁した読み（強い の ヅヨイ、作る の ヅクル）は複合語の中でしか出ない。文語の活用型の語（出す の イダス、文語四段-サ行）は今の文章の書き方ではない。くだけた読み（悪い の ワリイ、暑い の アチイ）は、語彙ファイルが辞書形と同じ表記の行（終止形と連体形）でしか持たない。

## 決定

- UniDic と SudachiDict full の語彙ファイル core_lex.csv、notcore_lex.csv の、固有名詞でない活用する語を、辞書形の行と、それを辞書形とする活用形の行をまとめて取る。表記に漢字を持つ語だけを取る。ほかの表記に正規化される書き方（行なう）は取らない。活用形が辞書形を指す書き方の後ろに付く語の番号（ref-）は除いて突き合わせる。
- Kanaemi が活用型を活用でき、語彙ファイルが辞書形と違う表記の活用形も持つ語は、辞書形から活用型の語尾を除いた語幹の行（から 辛 形容詞）を入れる。文章で、同じ表記と活用型の語幹が、読みを問わず 2 回以上出たときだけ入れる。コストは、その語幹が出た回数のコストに、文章に出た UniDic の語と同じ割増を足したもの。良い は 良っ（イッ）の行を持つので、語幹の行 い 良 形容詞 で入る。
- 活用表が扱わない語と、活用表が知らない活用型の語は、活用形のうち、表記の最後の漢字の後にひらがなが続くものを活用しない語として入れる。表記が文章に 2 回以上出たときだけ入れ、コストは活用しない語彙の語と同じに決める。
- 次の読みは入れない。
  - 同じ表記と活用型の別の語の読みの、最初の仮名を濁らせた読み（強い の づよい）。
  - 文語の活用型の語。
  - Kanaemi が活用型を活用できる語で、語彙ファイルが辞書形と同じ表記の形しか持たない読み（悪い の わりい）。
- 訂正の語の表記には、訂正の語と違う読みの行は入れない。
- 解析器の読みが誤りかどうかの見分けは、これまでどおり活用しない UniDic の語だけで行う。

## 検討した他の案

- 活用しない語と同じく、UniDic の語は文章に出なくても入れる：UniDic の活用する語は、方言形（あおくせえ）や文語の形を多く含む。文章に語幹の出ない語は、使われない語として入れない。
- 語彙ファイルの活用形を、それぞれ活用しない語として入れる：形ごとの行が並び、語幹から作る形と重なる。Kanaemi は語幹を活用して引くので、要るのは語幹の行である。
- 辞書形の行（からい 辛い）と送り仮名付きの語の行（から*い 辛い）も入れる：語幹の行から、どちらの打ち方でも引ける。文章に出た活用形の行は、出た回数で並びを決めるためのもので、文章に出ない読みには数がない。
- 連濁した読み、文語の語、辞書形と同じ表記の形しかない読みも入れる：語幹の出た回数は読みを問わず数えるので、行く や 取る のようによく出る語幹には、ゆ 行 と並んで ど 取、び 引 のような語幹の行が入る。打った読みに、複合語の中でしか出ない語や、くだけた書き方の候補が混ざる。
- 良い の イイ を活用表が扱わない語に加える：outside.tsv は辞書形の表記で語を決めるので、良い と書けば よい の 良い まで形ごとの語になる。
- いい の 良い を訂正の語に書く：訂正の語は解析器の読みを置き換えるので、よい で 良い が出なくなる。

## 結果

2026-11-08 に測った数字。

- いい で 良い、からい で 辛い、だく で 抱く、ゆく で 行く・逝く、いかる で 怒る、ひらける で 開ける が引ける。正解集（モデルなし）の候補に出ない語は 40 から 24 になった。気に いる の 入る は、候補に出るようになったが 7 番目。
- 基本辞書に約 370 行が入り、ほとんどが語幹の行。ファイルは 24.69MB から 24.71MB になる。
- 素材の文書での評価（モデルなし）は、候補に出ない単位が 10,123 から 10,120、損失が 21,850 から 21,855 になる。
- 連濁した読み、文語の語、辞書形と同じ表記の形しかない読みを除く前は約 590 行が入り、がらい、ぱってん のような読みで損失が増えた。語幹の行約 420 のうち約 100 は濁った読みで始まっていた。
- い 良 形容詞 からは、いく で 良く、いかった で 良かった も出る。
