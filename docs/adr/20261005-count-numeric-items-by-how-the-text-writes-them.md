# 数を含む語は、文章での書き方を数えて数値の項目にする

状態：採用

## 背景

Kanaemi の辞書は、数を含む語を数の置き場所で書ける（`{}こ	{kanji}個`）。打った数が置き場所に入り、表記の置き場所には語ごとの書き方（半角・全角・漢数字など）で書いた数が入る。数ごとに語を持つ必要はないが、どの語をどの書き方で持つかは辞書が決める。

解析器は、数と、その後ろの助数詞（本、年、歳）を別の語に分ける。助数詞の読みは前の数で変わらない 1 つで、3本 も 1本 も「ぽん」と読む。一方、利用者は数の後ろを音どおりに打つ（`3ぼん`、`1ぽん`）。

## 決定

- 数の直後の助数詞・接尾辞と、数の前の接頭辞（第3回 の 第）を、数とひとまとまりにした数値の項目にする。
- 表記の置き場所の書き方は、文章でその数がどう書かれていたかから決める（`3` は半角の数字、`三` は漢数字）。そのために、文章の全角の数字は半角にそろえない。
- 数を置き場所にした（読み, 表記）ごとに、数を問わず合わせて数え、ほかの語と同じ足切りとコストで項目にする。
- 助数詞の読みの最初のかなを濁らせた形と半濁らせた形も、同じ表記に当てる（`{}ほん`・`{}ぼん`・`{}ぽん` を `{}本` に）。
- 数だけの項目（`{}	{kanji}`）は作らない。

## 検討した他の案

- 助数詞の一覧を手で持ち、すべての書き方を付ける：語を文章から選ぶ原則に反する。どの書き方が多いかが分からず、並び順が決まらない。
- 解析器の読みをそのまま使う：音の変わる読み（3本＝さんぼん）で引けない。
- 数ごとの項目にする（`3ぼん	3本`）：打つ数が変わるたびに別の語になり、数え上げが散る。Kanaemi の数値変換も使えない。
- 数だけの項目も作る：数だけを漢数字などに変換する使い方は、文章からは数えられない。

## 結果

- 文章に出てこない助数詞や書き方は、辞書に入らない。
- 濁った形・半濁った形を足すので、実際には使われない読みの行（`{}ご	{}個`）も混ざる。その読みで打たれなければ候補に出ない。
- 全角の数字を半角にそろえないので、解析器が全角の数字を読めることに頼る。
