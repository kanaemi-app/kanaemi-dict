# 文章が選ぶ語に、人が確かめた別の読みを足す

状態：採用

## 背景

解析器は 1 つの表記に、文脈によらず 1 つの読みを付ける。もう 1 つのよく使う読みは、SudachiDict の語彙全体がその表記の別の語として持っていれば、文章に 2 回以上出た表記に足している（文章に出た語を、SudachiDict の語彙全体の読みでも読む、`20261011-read-the-text-s-words-as-the-whole-sudachidict-lexicon-reads-them.md`）。どの語彙も持たない読みは、文章からは作れない。

人が実際に使う読みで打って出ないと確かめた語に、次のものがある。

| 表記 | 足りない読み | 基本辞書の読み |
| --- | --- | --- |
| 空行 | からぎょう | くうぎょう |
| 朝会 | あさかい | ちょうかい |
| 未払い | みばらい（みばら*い） | みはらい |
| 脳汁 | のうじる | のうじゅう |
| 角丸 | かどまる | かくまる |

角丸 の かどまる は、SudachiDict の語彙に人名（姓）としてだけある。語彙の読みを足すときは人名と固有名詞を除くので、入らない。

訂正の語は、解析器の読みを置き換える。空行 を からぎょう にすると、くうぎょう で 空行 が出なくなる。

文章が読みを持つ所もある。Wikipedia の冒頭の 空行（からぎょう） のような括弧書きと、青空文庫のルビである。これを手がかりに、出た所ごとに読みを付け直す案は、変換に要るのが読みの行で読みの割合ではないとして採らなかった（同じ ADR）。だが、どの語彙にもない読みの行を見つける手段としては測っていなかった。

## 括弧書きの読みを測る

素材の文書（`build/docs.jsonl`）から、漢字の続き（後ろに 3 字までのひらがな）の直後に、ひらがなだけの括弧書きが続く所を拾い、基本辞書の表記と読みに比べた（2026-11-08）。青空文庫の文書は素材にする時点でルビを除いているので、括弧書きだけが手がかりになる。

| | 所 |
| --- | --- |
| 括弧書きの読みの付いた所 | 12,314 |
| 表記が基本辞書にない | 4,282 |
| 読みが基本辞書の読みと同じ | 5,992 |
| 基本辞書にない読み | 2,040（組では 1,734） |

基本辞書にない読みの組のうち、2 つ以上の文書に出るものは 45 組だった。組から 50 組を無作為に取って人が見ると、表記のその読みとして正しいものは 17 組（34%）で、多くは地名・人名・仏典の読みだった。ほかは、括弧が表記の一部にしか掛からないもの（地球温暖化（おんだんか））、表記より長いものの読み（政府専用機（だいかんみんこくのせいふせんようき））、当て読み（時間（とき）、尺度（ものさし））、読みでない添え書き（日記（こちら））である。

上の表の語は、どれも拾えなかった。どれも文書には出る（空行 は 37 行、未払い は 72 行）が、括弧書きの読みを付けた所は 1 つもない。普段の文章は、読み手が知っている語に読みを添えない。

## 決定

- 人が確かめた別の読みを、足す読みとして `analyzer/added-readings.tsv` に書く。1 行に 1 語を、表記と読み（ひらがな）のタブ区切りで書く。
- 足す読みの行は、SudachiDict の語彙全体の読みと同じに扱う。表記が文章に 2 回以上出たとき（複合語の切れ端は、複合語の外に出た回数で）だけ入れ、コストは表記の出た回数のコストに、語彙の読みと同じ割増を足したもの。数を持たない読みなので、語彙の読みと同じ見積もりにする。
- 送り仮名付きの語の行は、ほかの語と同じに足す読みの行から作る（未払い みばらい から みばら*い）。表に `*` は書かない。
- 解析器の読みは替えない。単位も替わらないので、素材の文書での評価と並べ替えのモデルの学習の単位は変わらない。
- 訂正の語の表記にも足せる。訂正の語の表記には訂正の語と違う語彙の読みは入れないが、足す読みは人が確かめた読みなので入れる。外す語の表記には足せない。
- 足す読みの行は、文章で選ばれ、ほかからは作れないときだけ置く。全文書から作る基本辞書で、表記が足切りの回数に届かない行と、足さなくても基本辞書にその読みと表記の行がある行（解析器、UniDic、語彙全体、記事の見出しなどから入るもの）があれば、辞書を書かずに失敗させ、その行を示す。学習用の文書だけの辞書では失敗させない。文書が少なく、足切りに届かない表記があるため。
- 追加辞書には当てない。

## 検討した他の案

- 括弧書きの読みから行を作る：上のとおり、足りない語を 1 つも拾えず、拾える組の 3 分の 2 は読みとして誤っている。結局人が見るなら、見る対象は打って出なかった語のほうがよい。
- 訂正の語に足す読みも書けるようにする（同じ表で、置き換えか足すかを列で分ける）：訂正の語は解析器の区切りに当てて単位を替え、`just check-corrections` で要るかを確かめる。足す読みは単位を替えず、確かめ方も違う。1 つの表に混ぜると、行ごとに当て方を読み分けることになる。
- 語彙の人名の読みも足す（角丸 の かどまる）：人名は表記を語として読まない読みを多く持つ（一日 の かずてる）。人名を足すと誤りの行が大量に入る。
- 表記が文章に出ていなくても入れる：語は文章から選ぶという方針に反する。足す読みは、文章が選んだ語に読みを足すだけにする。
- 足す読みの行に、手でコストを書く：数のない読みの割合を人が見積もることになる。Kanaemi は打たれた読みで候補を引き、コストを比べるのは同じ読みの候補の間だけなので、多くの語では行があることが効く。並びが合わない語は、正解集で見つけてから考える。

## 結果

- からぎょう で 空行、あさかい で 朝会、みばらい と みばら*い で 未払い、のうじる で 脳汁、かどまる で 角丸 が出る。基本辞書には、この表の語の行と 未払い の送り仮名付きの語の行だけが増え、ほかの行は変わらなかった（2026-11-08）。
- 解析器の読みと単位を替えないので、素材の文書での評価は変わらない。足す読みの効き目は、確かめの一覧で見る。
- 足す読みは手で保つ。打って出ない語を人が見つけ、使われる読みだと確かめてから足す。
- 足す読みの行が要らなくなる（解析器や語彙が読むようになる）と、基本辞書を作るときに失敗するので、その行を外す。
- 足した読みのコストは表記の回数から見積もるので、同じ読みのほかの語との並びが合わないことがある。
