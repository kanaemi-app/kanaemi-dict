# 文章は解析にだけ使い、素材のライセンスは問わない

状態：採用

## 背景

辞書に要る語は、文章から選ぶ。専門用語や新語の穴を埋めるには、素材の分野を広く取る必要がある。

配る辞書に入るのは、語の読みと表記の組と並び順だけで、素材の文章は入らない。読みと表記の組は事実で、1 件ずつ見れば著作物ではない。文章を集めて語を数えるのは情報解析のための利用で、著作権法 30 条の 4 により、素材のライセンスの条件にかかわらず原則として許される。

一方で、他人が作った辞書の項目一覧を丸ごと取り込むことは、データベースの著作物や不法行為として、素材のライセンスとは別に問題になりうる。

## 決定

- 素材の文章は、語を選び、出現を数え、並べ替えを学習するためにだけ読む。素材のライセンスの種類は問わない。
- 配る辞書と、リポジトリにコミットするものには、素材の文章を入れない。
- 取得は、サイトの利用規約と robots.txt に従い、公開元の負担にならない間隔で行う。取得を禁じているサイトからは取らない。
- 他の IME や辞書の項目一覧（SKK-JISYO、Mozc の辞書、NEologd、SudachiDict の語彙一覧の丸ごと）は取り込まない。
- 素材の表示は、条件として求められているかにかかわらず、礼儀として配布物の NOTICE に残す。

## 検討した他の案

- 利用の条件が明記された素材だけを使う：配る辞書のライセンスを縛る CC BY-SA の Wikipedia や、条件の説明が曖昧なサイトを使えず、分野が限られる。IT などの専門用語や新語が欠けたままになる。
- 他の辞書を土台にして語を足す：語彙はすぐ揃うが、他人の辞書の丸写しになる。
- LLM に語と読みの一覧を出させて辞書にする：出現の頻度が取れず並び順が決まらない。読みも誤る。

## 結果

- Wikipedia や CC BY-SA の文章、利用条件の説明が曖昧なサイトも素材にできる。制約は取得の作法だけになる。
- 素材に問題が見つかっても、配った辞書に文章は入っていないので、以後の取得をやめれば済む。
