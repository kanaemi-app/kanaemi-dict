# 漢字一字の読みは Mozc の単漢字の一覧から取り、語より後ろに並べて基本辞書に入れる

状態：採用

## 背景

基本辞書は文章に出た語から作るので、漢字一字がその読みで単独に使われない限り、一字の項目は生まれない。`すで*に 既に` はあっても `すで 既` はなく、漢字だけが分かる語を一字ずつ組み立てて打つ手段がない。文章から作れない語なので、条件を満たす他の一覧から取れる（他の辞書の項目一覧は、文章から作れない語に要り、再配布と改変が明記されているときに取り込む、による）。

Mozc の `src/data/single_kanji/single_kanji.tsv` は、読みと漢字の並びの表で、語幹の読み（`すで 既`、`おもんぱか 慮`）や促音・連濁の形（`かっ 活`、`ばら 払`）も持つ。リポジトリ全体が BSD-3-Clause で、再配布と改変が認められている。常用漢字はすべて入っている。基本辞書の語に出る漢字のうち、Mozc にない字は 170 ほど（中国の人名・地名の字、`髙` `吞` のような異体字）で、Unicode の Unihan の `kJapanese`（Unicode License v3）がそのほとんどに音読みを持つ。

## 決定

- 漢字一字の読みは、Mozc の単漢字の表から取る。1 行を字ごとの（読み, 字）の組にする。commit を固定して取る。
- 文章に出る漢字のうち Mozc にない字は、Unihan の `kJapanese` の音読み（カタカナ）をひらがなにして足す。訓読みは送り仮名の区切りがなく古い読みも多いので使わない。Unicode の版を固定して取る。
- Mozc の誤りらしい組（`おれえるさま 忙`）は、外す組の表 `kanji/excluded.tsv`（`読み<TAB>字`）に書いて除く。異体字（`旣`、`來`）は残し、気になる字だけ表で外す。
- 基本辞書に入れる。同じ（読み, 表記）の活用しない語が基本辞書にあれば、一字の項目は作らない。
- 一字の項目は、どの語よりも後ろに並べる。
  - 字の読みの裏付けは、自前の文章から取る。基本辞書の活用しない語の読みを、字ごとの読みに当てはめ、語の回数を（読み, 字）に配る。当てはめ方が複数あれば等分する。
  - 裏付けのある組のコストは `4096 + 回数のコスト`（8191 で止める）、ない組は `8192 + 字が文章に出た回数のコスト`。並べ替えのモデルはコストを `floor(log2(コスト + 1))` の帯で見るので、それぞれ帯 12 と 13 になる。語のコストは帯 11（UniDic にだけある語の 3000）までなので、モデルなしでも、語 → 裏付けのある一字 → ない一字の順に並び、学習し直したモデルはこの帯をまず選ばれないものと学べる。

## 検討した他の案

- Unihan だけから取る：送り仮名の区切りがなく、語幹の読み（すで）が取れない。古い読みも多い。
- KANJIDIC2、MJ文字情報一覧表：CC BY-SA で、継承の条件が CC BY 4.0 で配る辞書を縛る。
- SKK-JISYO：GPL。
- 常用漢字表：PDF しかなく、常用漢字は Mozc にすべてある。
- 追加辞書にする：利用者が足すまで打てず、並べ替えのモデルが見ない辞書の位置になる。
- 異体字を外す：外すには異体字の規則（Mozc の `variant_rule.txt`）が要り、素材が増える。帯 13 の最後に並ぶので、ふだんの候補には出ない。

## 結果

- `すで 既`、`かなら 必` のような一字の項目で、漢字を一字ずつ組み立てて打てる。
- 基本辞書の行が 3% ほど増える（基本辞書にない組が約 1.75 万）。
- 基本辞書を作り直したら、並べ替えのモデルも学習し直す。一字の項目が基本辞書に入ると、基本辞書だけで候補に出る語が増え、追加辞書から落ちる行がある。
- Mozc と Unihan の版を上げるときは、固定した commit と版を変えて作り直す。
- 配布物の NOTICE に Mozc（BSD-3-Clause）と Unihan（Unicode License v3）の表示を入れる。
