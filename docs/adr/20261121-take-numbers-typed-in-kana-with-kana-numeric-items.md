# かなで打った数を、数値の項目の {kana} で受ける

状態：採用（`20261006-make-small-counted-words-typed-with-kana-numbers.md` の検討した他の案のうち、Kanaemi がかなの数を数として読む案と、十より大きい数を入れる案の判断を置き換える）

## 背景

Kanaemi は読みの中の数を数字でしか受け取らなかったので、数値の項目は `12かい` と打てば引けても、`じゅうにかい` と打っては引けなかった。かなで打つ数は小さい数がほとんどだとして、一から十までの漢数字と助数詞の語（小さい数の語）を辞書に入れていた。

数を漢数字で書く人の多くは、数をかなで打つ。素材の文書で、漢数字で書かれ、かなの読みを持つ数値の単位を、数をかなで打つと、候補に出ないものが 4 割近くある（2026-11-21、学習用の文書だけの辞書）。多くは 第一項、第二条 のように接頭辞の付く数と、十一以上の数である。小さい数の語は接頭辞の付く形を持たず、十より大きい数は持たない。

Kanaemi v1.1.0 で、読みの置き場所 `{kana}` ができた。漢語のかなの数と、その音の変わった形（いっ、じゅっ、びゃく）を数として受け取る。`{kana}` の項目の候補は、同じ読みのほかの候補すべての後ろに置かれる。v1.1.1 で、同じ表記を `{kana}` でない項目も出すときは、コストによらずその項目の候補として出るようになった。

## 決定

- 置き場所が 1 つの数値の項目ごとに、読みの置き場所を `{kana}` にした行を、同じ表記とコストで書く（`{}かい	{kanji}回` → `{kana}かい	{kanji}回`、`だい{}かい` → `だい{kana}かい`）。表記の書き方（`{half-num}`・`{kanji}` など）は元の行のまま。
- 濁った読みと半濁った読みの行（`{}ぼん`・`{}ぽん`）からも作る。音の変わった数（さんびゃく、じゅっ）は Kanaemi が受け取るので、助数詞の側の読みは元の行のままでよい。
- 置き場所が 2 つ以上の行（`{}がつ{}にち`）からは作らない。
- 小さい数の語は残す。和語の数え方（ひとつ、みっか、ふたり）は `{kana}` が受け取らないので、小さい数の語の読みのまま引く。
- 評価に、漢数字で書かれ、かなの読みを持つ数値の単位を、数をかなで打つ打ち方を、打つ単位とは別に数える。

## 検討した他の案

- `{num}`（数字でもかなでも受け取る置き場所）で書く：`{}` の行と `{kana}` の行を 1 行にできるが、数字で打った候補まで `{kana}` と同じく後ろに回る。
- 小さい数の語を、接頭辞の付く形と十一以上の数にも広げる：組が数えきれない。
- 数を漢数字で書く項目（`{kanji}`）にだけ `{kana}` の行を書く：かなで打っても数字で書く人（12回）の候補が出ない。どちらで書くかは、数字で打つときと同じく、項目のコストで決める。
- 小さい数の語を外す：和語の数え方を引けなくなり、`{kana}` の候補は後ろに回るので、一本 が イッポン の後ろに下がる。
- 同じ表記の語より `{kana}` の行が安いとき、辞書の側でその行のコストを上げる：接頭辞の付く語（第四条）まで見て回る必要があり、Kanaemi の候補のまとめ方を直すほうが一度で済む（v1.1.1）。

## 結果

- 十一以上の数と、接頭辞の付く数（だいじゅうにかい、だいいちじょう）も、かなで打って引ける。
- 学習用の文書だけの辞書、並べ替えのモデルなしでの評価（2026-11-21、Kanaemi v1.1.1）。行は `{}` の数値の項目と同じ 14,109 行増える。

  | | 足す前 | 足した後 |
  | --- | --- | --- |
  | かなで打った漢数字の数（12,134 単位）の候補に出ない数 | 4,701 | 231 |
  | 同じく 1 位 / 最良の並べ方での 1 位 | 6,413 / 7,118 | 8,948 / 11,557 |
  | 打つ単位の語の候補に出ない数 | 9,642 | 9,603 |
  | 打つ単位の語の損失 | 21,295 | 21,357 |
  | 打つ単位の複合語の損失 | 763 | 763 |

- `{kana}` の候補は、同じ読みを区切って作った候補（第一項 に対する ダイ一行、第一条 に対する 第一城）の後ろにも回る。かなで打つ数の損失の多くはこれで、並べ替えのモデルで前に出すことになる。
- 打つ単位の語の損失が増えた分は、辞書にない語で、数の読みで始まるもの（十二天 が 12点 の後ろ、センネット が 1000ネット の後ろ）である。足す前は候補に出ないか、カタカナの候補だけが出ていた。
- 和語の数え方の助数詞の行（`{kana}つ	{kanji}つ`）もでき、さんつ と打つと 三つ が出る。ふつうは打たない読みで、ほかの候補を押しのけることは少ない。
