# 辞書は手元で作ってコミットし、CI は配布物にまとめるだけにする

状態：採用

## 背景

辞書と並べ替えのモデルを素材の取得から作るには、数 GB の素材を、公開元が求める間隔を守って取得し、解析して数え、学習する必要がある。取得だけで 1 時間を超え、取得のたびに公開元に負担をかける。取得の量を減らすと、辞書の正解率が下がる。

一方で、辞書とモデルは素材の文章を含まないので、リポジトリにコミットしてよい。

## 決定

- 辞書と並べ替えのモデルは、手元で素材の取得から作り、評価してから、リポジトリにコミットする。
- CI は、コミットされた辞書とモデルを確かめ、素材の表示とライセンスを付けて配布物にまとめるだけにする。素材の取得、解析、学習は行わない。
- 基本辞書とモデルは、組にしてコミットし、組にして配る。

## 検討した他の案

- CI で素材の取得から作る：取得と学習で 1 時間を超え、作るたびに公開元に負担をかける。取得の量を減らすと正解率が下がる。
- CI での取得を何回かの実行に分ける：保管庫がそろうまで辞書ができず、実行のたびの所要時間も読めない。
- 数えた回数をコミットし、CI でコストを計算する：コストの決め方を変えるには評価が要り、評価には手元の文書が要るので、CI で計算する利点がない。

## 結果

- CI は数分で終わる。
- 辞書の更新は、手元で作り直して評価し、コミットする作業になる。
- 辞書のファイルがリポジトリに入るので、更新のたびに数 MB の差分が出る。
