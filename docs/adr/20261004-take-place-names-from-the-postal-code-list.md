# 地名は郵便番号データの一覧から取る

状態：一部置き換え（「例外は、公的機関が配る地名の一覧に限る」の行は `20261007-take-other-lists-only-for-words-text-cannot-make.md` で置き換えた）

## 背景

辞書に入れる語は、集めた文章に実際に出てきたものから選ぶ。しかし地名、とくに町や字の名前は、ほとんどが文章に一度も出てこない。出てきても回数が少なく、足切りで落ちる。読みも、解析器が誤りやすい。

日本郵便の郵便番号データは、全国の都道府県・市区町村・町域の表記と読みの一覧で、自由に配ってよいと明記されている。他の IME や辞書の項目一覧ではない。

## 決定

- 地名の追加辞書は、郵便番号データの地名と読みから、文章を通さずに作る。語は文章から選ぶ、の例外とする。
- 地名のコストは、その地名を持つ郵便番号データの行の数から決める。
- 他の辞書の項目一覧を取り込まないことは変えない。例外は、公的機関が配る地名の一覧に限る。

## 検討した他の案

- 地名も文章から選ぶ：町や字の名前はほとんど文章に出てこず、辞書に入らない。
- 地名の辞書を持たない：住所を打つたびに、地名を 1 字ずつ変換することになる。
- 解析器の辞書の地名を使う：他人の辞書の項目一覧を写すことになる。

## 結果

- 地名の辞書の項目は、文章での使われ方ではなく、一覧に載っているかで決まる。
- 郵便番号データにない地名（旧地名や通称）は、文章から入らない限り辞書に入らない。
