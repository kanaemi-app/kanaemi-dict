# 活用表が知らない活用型の語の形は、活用しない語として入れる

状態：採用

## 背景

辞書は、Kanaemi の活用表が知らない活用型（文語形容詞-ク、文語助動詞-ゴトシ、文語四段-ハ行 など）の語を入れていなかった。Kanaemi はその型の語幹から形を作れないので、語幹の行は使えない。形そのものも入れていなかった。

素材の文書での評価で、候補に出なかった単位を Kanaemi の変換の経緯（`Engine::explain`）で分けた。理由が「活用で落ちた」ものの多くは、文語の形容詞の形（若き、良き、亡き、少なから）だった。形容詞の語幹 若 から 若き を作ろうとして、活用表に き がないので落ちる。辞書にないものも合わせ、こうした単位で候補に出なかったものは 621 あった（如く 80、如き 30、若き 29、恐る 23、良き 20）。

評価は、こうした単位を活用しない語として、送り仮名を指定せずに打つ。活用表が扱わない語（来る、いい）の形は、すでに活用しない語として入れている。

## 決定

- 活用表が知らない活用型の単位は、語幹を作らない。その形は、活用しない語として数えて入れる。
- 表記の最後の漢字の後にひらがなが続き、その分を読みの終わりに持つ形だけ数える。表記が漢字だけの形は、ほとんどが解析器の読み違いなので、単位からは数えない（深掘り を 深＝こし＋掘り と読んだもの）。UniDic や語彙全体が活用しない語として持つ行（そうろう 候）は、これまでどおりほかの語と同じに入る。
- これまでどおり、活用型と単位の数を報告する。

## 検討した他の案

- 入れない：今も書かれる 如く、良き、亡き が候補に出ない。
- Kanaemi の活用表に文語の型を足す：活用表は今の日本語の打ち方のためのもので、文語の形は文書に出たものを語として持てば足りる。
- 漢字だけの形も入れる：解析器が文語の活用と読んだ漢字だけの表記は、複合語を分けて読み違えたものが多い。

## 結果

- 学習用の文書だけの基本辞書に、文語の形が 655 語入った（思ふ、云ふ、良き、美しき）。
- 素材の文書で、語の候補に出ない単位が 9,037 から 8,491 になった。
