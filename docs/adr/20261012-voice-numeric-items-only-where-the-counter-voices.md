# 数値の項目の濁った読みは、濁る助数詞にだけ足す

状態：採用（`20261005-count-numeric-items-by-how-the-text-writes-them.md` の決定のうち、助数詞の読みの濁った形・半濁った形をどれにも当てる行を置き換える）

## 背景

数値の項目は、助数詞の読みの最初のかなを濁らせた形と半濁らせた形も、同じ表記に当てていた（`{}ほん`・`{}ぼん`・`{}ぽん` を `{}本` に）。解析器は 本 を数によらず ぽん と読むので、利用者が音どおりに打つ ほん・ぼん で引けるようにするためだった。

これを、どの助数詞にも当てていた。回 にも `{}がい`、月 にも `{}かつ` の行ができ、`3がい` と打つと 3回（コスト 793）が 3階（916）より先に出た。使われない読みの行は、その読みで打たれなければ候補に出ないとしていたが、別の助数詞が本当にその読みで打たれる（三階＝さんがい）と、並びを崩す。

数の後ろで助数詞の音が変わる規則（小さい数の語の規則）で、濁ったり半濁ったりするのは は行 だけで、か行・さ行・た行 は数のほうが促音になるだけである。か行で濁る 三階＝さんがい は規則の例外で、訂正の語に書いてある。解析器は 階 を数の後ろでも かい と読み、文書の単位に がい は出てこない。

## 決定

- は行の助数詞は、これまでどおり、最初のかなの濁らない形・濁った形・半濁った形の行をすべて作る。
- ほかの行の助数詞には、濁った形の行を作らない。
- 一〜十の漢数字と助数詞の語（小さい数の語と、文書から入った同じ形の語）の読みで、助数詞の頭が規則と違って濁っているもの（三階＝さんがい、三軒＝さんげん）があれば、その助数詞の数値の項目に、どの数の書き方にも、その濁った読みの行を足す。コストは濁らない読みの行と同じにする。

## 検討した他の案

- 文書の単位で濁って出た読みだけに行を作る：解析器は か行・さ行 の助数詞を数の後ろで濁らせて読まないので、階 の がい の行もなくなり、`3がい` で 3階 が出なくなる。
- 濁る助数詞の一覧を手で持つ：例外は訂正の語にもう書いてあり、二か所で持つことになる。
- これまでどおりどの助数詞にも当てる：実際に濁る別の助数詞の並びを崩す。

## 結果

- `3がい` で 3回 や 3界 が出ず、3階 が出る。
- 規則と違って濁る助数詞は、訂正の語に小さい数の語を 1 行書けば（三軒＝さんげん）、数字で打つときにも効く。
- か行・さ行・た行の助数詞の、濁った読みだけの行（`{}かつ	{}月`、`{}ご	{}個`）は辞書から消える。
