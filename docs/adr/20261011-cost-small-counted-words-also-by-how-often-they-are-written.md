# 小さい数の語のコストを、その表記が書かれた回数でも決める

状態：採用（`20261006-make-small-counted-words-typed-with-kana-numbers.md` の決定のうち、コストの行を置き換える）

## 背景

小さい数の語（一匹〜十匹）のコストは、その助数詞の数値の項目のコストに、十の数から 1 つを選ぶ分（−ln(1/10) × 100 = 230）を足していた。どの数も同じコストになる。

文章では、一 が他の数よりずっと多く書かれ、決まった言い方にもなる（一発で、一発勝負）。解析器は 一発 を 一＋発 と区切るので、文書の 一発 はすべて数値の項目 `{kanji}発` に数えられ、語 一発 としては数えられない。いっぱつ 一発 は 1304 で、三発・十発 と同じだった。一方、危機一髪・間一髪 から切り出された 一髪 が 1309 になり、いっぱつ と打つと 一発 と 一髪 がほぼ並んでいた。

数値の単位は、数を置き場所にした表記（`{kanji}発`）のほかに、書かれたとおりの表記（一発）を持つ。素材では 一発 と書かれた単位が 484 あり、一髪 として数えた 50 回より多い。

## 決定

- 数値の単位を、書かれたとおりの表記ごとにも数える（一発、3本）。2 回以上出た表記に、出た回数からコストを付ける。
- 小さい数の語のコストは、今までのコスト（助数詞の数値の項目のコストに 230 を足したもの）と、同じ表記の数値の単位のコストの小さいほうにする。
- 読みは区別しない。小さい数の語は、表記ごとに読みを 1 つしか持たないため。

## 検討した他の案

- 数ごとの割合を、助数詞によらず全体で決める（一 は 4 割など）：一発 のように 一 にほぼ限られる語と、三日 のように数が散らばる語を分けられない。
- 書かれた表記のうち、後ろに助数詞のほかの語が続く単位を数えない（一眼レフ の 一眼、第二類 の 二類）：そうした所でも表記は同じに打たれる。モデルありの評価で値は下がらなかったので、区別しない。
- 間一髪 などの複合語の中に出た 一髪 を数えない：一髪 は下がるが、新聞（765 → 907）、株式（774 → 987）、大臣（858 → 1051）のような、複合語の中に多く出るふつうの語も下がる。文書での第一候補は 0.1 ポイントあまり下がった。一発 が先に出るには、この決定で足りる。

## 結果

- いっぱつ の 一発 と 一髪 の差は 5 から 227 に開く（一発 1082、一髪 1309）。前の文なしでは前から 一発 が先だったが、差が小さく、前の文や並べ替えのモデルで入れ替わりやすかった。
- 一〜十 のうち、文章でよく書かれる語ほど安くなる。一日中、一本立ち のように、助数詞が長く、一 でしか書かれない語は 230 下がる。
- 読みの最も安い語が入れ替わる組がある。六条 → 六畳、一蹴 → 一周 のような、数の語がよく書かれる組のほか、一丸 → 一眼、二塁 → 二類 のように、長い語の中で書かれた分で数の語が先になる組もある。文脈は並べ替えのモデルが補う。
- 素材の文書での第一候補は、モデルありで確定履歴なし 89.45 → 89.47、ありで 92.54 → 92.50 と、ほぼ変わらない。この評価は数を数字で打つので、かなの数で打つ語の変化は測れない。正解集の かなの数 に いっぱつ 一発 を足して見張る。
