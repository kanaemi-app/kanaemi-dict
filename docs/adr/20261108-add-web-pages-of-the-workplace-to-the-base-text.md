# Web の文章から、仕事の場の語が多い文書を基本辞書の素材に足す

状態：採用

## 背景

仕事のチャットやメールで打つ語（打ち合わせ、議事録、工数、検収、稟議、障害対応）は、使う人が多く、分野の語ではない。基本辞書に要る。

基本辞書の素材は、小説、法令、技術文書、ニュース、Wikipedia、Web の文章で、仕事の場の文章は少ない。会議・プロジェクト管理・開発・運用・営業と契約・経理・人事・経営の語を自分で書き出して数えると（209 語、2026-11-08）、素材 1.18 億字に 100 万字あたり 325 回しか出ず、語として 2 回以上出るのは 179 語だった。開発の語がいちばん少ない。

仕事の場の文章をまとめて配る公開の素材は少ない。チャットの文章はない。有価証券報告書（EDINET）や官公庁のサイトは、仕事の語は多いが、経営会議や行政の語に偏る。

Web の文章（FineWeb-2 の日本語の train の分割）は、最初のファイルだけで 40 億字あり、基本辞書はその先頭の 4,000 万字しか使っていない。残りの中には、会社のサイト、求人、技術ブログ、業務の解説のように、仕事の場の語が多い文書がある。

## 決定

- FineWeb-2 の日本語の train の分割の最初のファイルから、基本辞書がすでに使う先頭の文書より後ろの文書のうち、仕事の場の語を多く含む文書を、5,000 万字まで基本辞書の素材に足す。
- 仕事の場の語を多く含む文書は、弊社・御社・案件・エンジニア・社内・ミーティング・タスク・チーム のうち 3 語以上を本文の日本語の行に含む文書とする。語はそれぞれ、何回出ても 1 語と数える。
- そのうち、求人の語（応募・月給・時給・年収・募集要項・求人・採用情報・給与・福利厚生・自己PR・転職・選考）を 2 語以上含む文書は求人の文書として足さない。1 語だけなら、会社のサイトの「採用情報」へのリンクのように、求人でない文書にもよく出る。
- 足した文書は、文書 ID を `fineweb2-business:` で始めて、ほかの Web の文章と分けて数え、評価する。出所 ID は同じファイルのものなので、配布物の素材の表示は変わらない。
- 足すかどうかは、もとからある素材の評価用の文書で測る。評価用の文書は文書 ID から決まるので、素材を足しても、もとからある素材の評価用の文書は変わらない。

## 検討した他の案

- 仕事の場の追加辞書を作る：基本辞書は分野に偏らないが、打ち合わせ や 議事録 のように、ほとんどの人が打つ語を、選んだ人しか引けない。分野の語でないので、[基本辞書と、それに足す追加辞書に分ける](20261004-split-into-base-and-additional-dictionaries.md) の追加辞書に当たらない。
- Web の文章を無作為に増やす：仕事の場の語が 10 回以上出る語の数を同じだけ増やすのに、約 4 億字が要る。基本辞書を作る時間も大きさも増え、8,000 万字から先は一般の文章の正解率もほとんど伸びない（[評価で決めた辞書の値](../references/evaluation-experiments.md) の「素材の量と組み合わせ」）。
- URL が `.co.jp` のページを足す：2.2 億字あるが、仕事の場の語は 100 万字あたり基本辞書の素材の 2 倍しか出ない。語を選んで抜き出した文書は 5 倍。
- 求人の文書も足す：仕事の場の語を多く含む文書の字数の 4 割ほどが求人の文書で、求人の語が一般の語より先に出るようになる。求人の文書も足して作り直すと、じこ で 自己（自己PR、自己分析）が 事故 より先に出て、もとからある素材の評価用の文書で、先頭に出ない語が増えた。求人の文書を除いても、仕事の場の語は 100 万字あたり基本辞書の素材の約 5 倍出る。
- 有価証券報告書（EDINET）や官公庁のサイトを足す：仕事の語は多いが、経営会議 や行政の語に偏る。
- 足した文書を評価から外す：仕事の場の文章で正解率が上がるかを測れない。

## 結果

- 足す文書は、ファイルの終わりまで読んで 2,768 万字（5,527 文書）になり、5,000 万字に届かない。求人の文書を除く前は 4,659 万字だった。
- 仕事の場の語のうち基本辞書にある語は、自分で書き出した 209 語のうち 152 語から 159 語になる（認識合わせ、課題管理、正常系、異常系、技術的負債、冪等性、予実）。開発の語がいちばん増える。
- もとからある素材の評価用の文書（モデルなし）で、候補に出ない単位は 10,126 から 9,745、先頭に出ない損失は 44,846 から 44,678 になる。Web の文章、法令、技術文書は損失が減り、Wikipedia（+95）、ニュース（+85）、小説（+78）は少し増える。求人の文書も足すと損失は 45,483 に増えた。
- 基本辞書から 107 行が外れる。多くは、素材が増えて長い語の一部だとわかった単位の連なり（委託契約 は 業務委託契約、タスクマネージャ は タスクマネージャー の一部として出る）で、長いほうは辞書にある。
- 外部の語の一覧では、候補に出ない語が 40 語から 39 語になる。
