# 文章に出た語を、SudachiDict の語彙全体の読みでも読む

状態：採用

## 背景

おおもじ と打っても 大文字 が出なかった。素材の文章に 大文字 は 300 回あまり出て、多くは Python やプログラミングの文書の おおもじ だが、基本辞書には だいもんじ の行しかなかった。

SudachiDict の語彙は 大文字 を オオモジ と ダイモンジ の 2 語で持ち、どちらも同じ品詞である。品詞が同じ語の間では、解析器は前後の文脈を見ず、コストの小さい語を選ぶ。そのため 大文字 は、文章のどこでも だいもんじ と読まれる。同じ表記を文脈で読み分ける語（同形異音語）は、少ないほうの読みが文章から作れない。

これまでも、UniDic（SudachiDict small の語彙ファイル small_lex.csv）の語は、文章から作れない読みとして基本辞書に入れていた。だが SudachiDict full の語彙のうち small_lex.csv にない部分（core_lex.csv、notcore_lex.csv）は見ていなかった。おおもじ は core_lex.csv にしかない。

同じ理由で、接頭辞・接尾辞をつないだ語の読みの確かめも漏れていた。つないだ語の読みは前後の語の読みをつないだもので、表記が UniDic にあれば UniDic の読みと比べて直す。表記が UniDic になければ、つないだ読みのまま入る。そのため 大掃除 が だいそうじ、宇宙人 が うちゅうにん、日本海 が にっぽんかい と読まれていた。どれも core_lex.csv か notcore_lex.csv には正しい読みがある。

Kanaemi は打たれた読みで候補を引くので、コストを比べるのは同じ読みの候補の間だけである。大文字 を おおもじ と だいもんじ のどちらでどれだけ書くかの割合は、変換に効かない。足りないのは、少ないほうの読みの行そのものである。

## 決定

- SudachiDict full の語彙ファイル core_lex.csv と notcore_lex.csv を、small_lex.csv と同じ版で取る。
- 接頭辞・接尾辞をつないだ語と数詞をつないだ語の読みは、UniDic とこの 2 つの語彙ファイルの人名でない語を合わせた読みと比べて直す。直し方はこれまでと同じだが、語彙の読みが 1 つで、前の語の読みで始まらず後ろの語の読みで終わりもしないときは、同じ表記の別の語（下山中 の地名 しもやまなか、最高値 の さいたかね）とみなし、つないだ読みのままにする。語彙は表記が同じなら別の語の読みでも返すので、1 つしかないことは、その読みが正しいことを意味しない。人名は表記を語としては読まない読みで持つ（一日 を かずてる）。人名でない固有名詞は使う。SudachiDict は 宇宙人、台湾人 を固有名詞、日本海 を地名としてだけ持ち、その読みが正しい。
- 文章に 2 回以上出た表記には、この 2 つの語彙ファイルの固有名詞でない語の読みの行を基本辞書に入れる。コストは、文章に出た UniDic の語と同じく、表記が出た回数のコストに割増を足したもの。1 回だけの表記と固有名詞まで入れると、作品名・会社名・地名の読みと、文章の足切りに届かない複合語が 5 万行あまり入る。訂正の語の表記には、訂正の語と違う読みは入れない。訂正の語は、その表記の読みを人が決めたもので、語彙の読みで誤りを戻さない（一回 の いちかい）。
- 解析器の読みが誤りかどうかの見分けは、これまでどおり UniDic だけで行う。

## 検討した他の案

- 文脈で読みを付け直す（ルビや括弧書きの読み、読みの決まった複合語、同じ文書で読みが揃うことを手がかりに、出た箇所ごとに読みを決める）：変換に要るのは読みの行があることで、読みの間の割合ではない。仕組みが大きいわりに、足す行は同じになる。
- 訂正の語に 大文字 おおもじ と書く：訂正の語は解析器の読みを置き換えるので、だいもんじ で 大文字 が出なくなる。同形異音語ごとに書くのでは漏れる。
- 語彙ファイルの語を、文章に出たかどうかによらず入れる：文章で選ぶという方針に反し、使われない語と固有名詞が大量に入る。
- 読みの確かめでも固有名詞をすべて除く：宇宙人、台湾人、日本海 の正しい読みが固有名詞の行にしかなく、うちゅうにん、たいわんにん、にっぽんかい のまま残る。
- 解析器の読みの誤りの見分けにも語彙全体を使う：解析器の読みは SudachiDict full の語彙から付くので、語彙全体と比べれば必ず合い、誤りを見分けられなくなる。
- 解析器を UniDic と MeCab に替える：品詞が同じ語をコストだけで選ぶのは同じで、文脈で読み分けない。

## 結果

- おおもじ で 大文字、おふだ で お札、おおじしん で 大地震 が出る。
- 大掃除、宇宙人、日本海 のように、つないだ読みが誤っていた語が、正しい読みで入る。
- `just sudachi` の取るファイルが増え、展開すると 1 GB 近くになる。
- 足した読みのコストは、文章に出た回数ではなく表記の回数から見積もるので、同じ読みのほかの語との並びが合わないことがある。合わない語は、正解集で見つけて個別に直す。
