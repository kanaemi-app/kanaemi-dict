# 解析器の読みを確かめ、誤りを直す

状態：採用

## 背景

辞書の語の読みは、解析器（Sudachi と SudachiDict full）が文章に付けた読みから取る。その読みには誤りが混ざり、誤った読みはそのまま辞書の項目になる。正しい読みで打っても語が出ず、誤った読みで打つと出る。

誤りは次の所から来る。

- 解析器は、接頭辞（大、小、深）や接尾辞（中、状）を別の語として返す。ひとまとまりにするときに読みをそのままつなぐと、連濁や読みの選び分けが抜ける（大相撲＝おおすもう、小部屋＝こへや、国中＝くにちゅう）。接頭辞を動詞や形容詞にもつなぐと、ない語ができる（お願い から お願う、突当る＝とっあたる）。
- SudachiDict full が UniDic に足している語（NEologd の人名・地名など）が、文脈に合わない読みで選ばれる（米子＝よなこ、長野＝おさの）。
- 解析器の辞書にない複合語は、分けて読まれる。その片方が文語の活用として読まれると、語にならずに落ちる（深掘り が 深＝こし＋掘り になり、ふかぼり の項目ができない）。

素材の文章は読みを持たないので、正しい読みは解析器か、ほかの語彙から知るしかない。

## 決定

- 接頭辞は、後ろの名詞・形状詞とだけひとまとまりにする。動詞・形容詞にはつながない。
- 接頭辞・接尾辞とひとまとまりにした語の表記が UniDic にあるときは、つないだ読みを UniDic の読みで確かめる。合わなければ UniDic の読みに替える。替える読みが 1 つに決まらなければ、ひとまとまりにしない。
- 活用しない語の読みが、その表記の UniDic の読みのどれとも合わないときは、同じ文を SudachiDict small（UniDic の語彙だけの辞書）でも読む。同じ位置で同じ表記の語に UniDic にある読みが付いていれば、その読みに替える。
- それでも直らない誤りは、このリポジトリに置く訂正の語で直す。訂正の語は表記と読みの組で、人が書き、文章に出た語の誤りを直すためだけに足す。
- 訂正の語は、解析器が読んだあとの区切りに当てる。続いた区切りの表記をつないだものが訂正の語の表記と同じなら、1 つの名詞にまとめて訂正の語の読みにする（深＋掘り を 深掘り＝ふかぼり に）。
- 語でないのに辞書に入る表記は、外す語として訂正の語と同じ表に書き、辞書に入れない。

## 検討した他の案

- 解析器を替える（MeCab と UniDic、Open JTalk）：どれも 深掘り を ふかぼり と読めない。辞書にない複合語の連濁を推し量る仕組みはどの解析器にもない。UniDic だけの解析器は語を分けすぎ、ひとまとまりにすると読みを誤る（子会社＝こかいしゃ）。Open JTalk の辞書は読み上げ用で、読みでなく発音（長音、アクセント）を返す。
- 辞書を作った後に訂正表を当てる：読みは直せても区切りは直せない。落ちた語（深掘り）は戻らない。
- 接頭辞・接尾辞をつながない：山田さん、彼ら、大相撲 のような、ひとまとまりで打つ語が入らなくなる。
- 表記が UniDic にある語は、いつも UniDic の読みにする：UniDic の読みが複数あると、文脈なしにはどれか決まらない。解析器の読みが UniDic にない正しい読み（人名の別の読み）のこともある。
- 訂正の語を、ほかの辞書から取り込む：他人の語彙一覧を写すことになる（Sudachi で読み、その語彙一覧は写さない、による）。
- 訂正の語を、解析器のユーザー辞書として足す：解析器が選ぶとは限らない。ほかの区切り方より安いコストを付けないと選ばれず（九時間 が 九＋時間 になる）、どこまで下げても選ばれない語もある（七日間 が 七＋日間 のまま）。語ごとに品詞、接続 ID、コストを書くことになる。

## 結果

- 文章を 2 つの辞書で読むので、単位を切る時間が延びる。SudachiDict small の取得が増え、配布物の表示に加わる。
- UniDic にない複合語の連濁や読みの選び分けは、訂正の語を足さない限り直らない。
- 訂正の語は手で保つ。足すべき語は、作った辞書の読みを UniDic と比べた食い違いから人が選ぶ。
- 語の境目が解析器の区切りの途中にあると、訂正の語は当たらない。
- 訂正の語の表記が文章に出れば、どの文脈でも当たる（三分 を さんぷん にすると、三分の一 も さんぷん になる）。
