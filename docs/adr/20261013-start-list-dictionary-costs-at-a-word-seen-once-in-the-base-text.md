# 一覧から作る追加辞書のコストは、基本辞書の文章に 1 回出た語のコストから始める

状態：採用

## 背景

人名・地名・駅名の追加辞書は、文章ではなく一覧から作り、コストを一覧の中の割合で決める。人名のフルネームは人物の重みの総和に対する割合、姓・名は人物の数に対する割合、地名は郵便番号データの行の数に対する割合、駅名は駅の重みの総和に対する割合で決める。基本辞書のコストは、文章の単位の総数（約 2,400 万）に対する割合で決める。一覧の分母は文章の単位の総数よりずっと小さいので、一覧の語は基本辞書の語より安くなる。基本辞書では、文章に 2 回出た語のコストが 1630、1 回なら 1699 になる。

| 辞書 | 最も安い項目 | 最も高い項目 |
| --- | --- | --- |
| 人名 | 819 | 1414 |
| 地名 | 602 | 1173 |
| 駅名 | 826 | 1166 |

一覧の語は基本辞書にない語なので、基本辞書の文章には 1 回以下しか出ていない。それなのに、2 人しか持たない名（侃士 かんじ、1183）が、文章に何度も出る語（浩二 1221、健司 1311）より安くなる。

Kanaemi の並べ替えのモデルは、コストを 2 を底とする対数の幅で見る（512〜1023、1024〜2047 など）。重みは 512〜1023 の幅が最も大きく（+3.5）、1024〜2047 の幅はほぼ 0 になる。一覧の語の多くは 512〜1023 の幅に入り（駅名は 94%）、文章に出る語より上に並ぶ。基本辞書のコストを文章での頻度とみなし、読みごとに最も安い語を文脈なしの正解とする代わりの評価を行った。人名・地名・駅名の辞書と読みが重なる 13,128 読みのうち、3,049 読みで一覧の語が 1 位になった。モデルなしでは辞書の並び順が先に立つので、この入れ替わりは起きない。

## 決定

- 人名・地名・駅名の辞書は、辞書の中で最も安い項目が、基本辞書の文章に 1 回出た語のコスト（`cost_of(1, 基本辞書の単位の総数)`）になるように、すべての項目のコストを同じだけずらす。辞書の中のコストの差は変えない。
- 基本辞書を作るときに、このコストを書き残す。追加辞書を作るときは、前提にする基本辞書のものを読む。配る追加辞書は全文書の基本辞書のもの、評価用の追加辞書は学習用の文書だけの基本辞書のものを使う。
- 分野の辞書、その年の新語の辞書、送り仮名の揺れの辞書、記号・絵文字・顔文字の辞書は変えない。

## 検討した他の案

- 一律に足す（+300、+500）：代わりの評価で、+300 と +500 の結果は同じだった。どちらも一覧の語が 1024〜2047 の幅に入るためで、足す量に根拠がない。一覧の大きさが変わると合わなくなる。
- 2048 から始める：代わりの評価では、1 位に来る一覧の語は 26 読みになり、基本辞書だけのときとほぼ同じ並びに戻る。しかし 2048 は、モデルがコストを見る幅の境目に合わせた値で、モデルの特徴の作り方が変わると意味を失う。辞書の値は、文章での頻度の尺度で決める。
- 同じ読みの基本辞書の語より必ず後ろにする：文章に出なかった UniDic の語（3000）よりも後ろに回り、よく知られた人名より、文章に出ない語が先に出る。
- 一覧の語を基本辞書の文章で数え直す：基本辞書にない語は文章に 1 回以下しか出ないので、数え直しても差がつかない。
- 分野の辞書も同じにする：分野の辞書のコストは分野の文章での頻度で、その分野の文章では基本辞書の語より多く使われる語を持つ。代わりの評価は基本辞書の頻度を正解にするので、分野の辞書の良し悪しは分からない。分野の文書で測ってから決める。
- Kanaemi の側で、後ろの辞書の候補のコストを足す：辞書の作り方で決まるコストの尺度を、辞書を読む側が辞書ごとに補うことになる。利用者が作った辞書の尺度は、Kanaemi には分からない。

## 結果

- 代わりの評価で、読みが重なる読みのうち 1 位が最も安い基本辞書の語になる割合は、70.3% から 89.0% になる（基本辞書だけのときは 92.0%）。1 位に来る一覧の語は、3,049 読みから 410 読みになる。根拠は [評価で決めた辞書の値](../references/evaluation-experiments.md) の「一覧から作る追加辞書のコスト」。
- 評価用の文書をモデルありで変換すると、3 つの辞書を並べたときの損失は 13,107 から 7,791 になる（基本辞書だけのときは 5,027）。候補に出ない単位の数は変わらない。根拠は同じ節の「評価用の文書で測った並び」。
- 残る 410 読みは、一覧の語と基本辞書の語のコストが同じ幅に入り、モデルの表層の特徴の重みで並びが決まるもの。学習していない語の重みは、重みの位置の衝突による雑音になっている。モデルの特徴の作り方を変えるまで残る。
- 一覧の辞書の中の並びは変わらない。
- 一覧の辞書は、これまでどおり基本辞書を前提にする。基本辞書を作り直したら作り直す。
