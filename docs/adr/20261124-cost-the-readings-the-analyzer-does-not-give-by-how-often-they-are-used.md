# 解析器の付けない読みのコストを、その読みの使われ方から見積もる

状態：採用（`20261011-read-the-text-s-words-as-the-whole-sudachidict-lexicon-reads-them.md` と UniDic の語の、割増の決め方を改める）

## 背景

あした と打つと 晨 が、なんじ と打つと 汝 が先頭に出て、明日 と 何時 が出てこなかった。

解析器は 1 つの表記にほぼ 1 つの読みを付ける。素材の 明日 は 3,878 回が あす、51 回が みょうにち で、あした は 1 回もない。語彙がほかの読みを持つ表記には、その読みの行を、表記の回数のコストに一律 1000 を足して入れていた。1000 は、頻度にして 2 万分の 1 にあたる。あした 明日 は 1893 になり、1417 の 晨 に負けていた。

「コストを比べるのは同じ読みの候補の間だけなので、読みの割合は変換に効かない」としてきた。これは、割り引く前のコストに近い割増なら成り立つ。1000 では、どの語にも負けるほど下がる。同じ形で、表記がよく出るのに先頭でない行が 554 あった（みんな の 皆、わたし の 私）。

何時 は別の形で欠けていた。なんじ という 1 語をどの語彙も持たない。何時 は いつ か なんどき と読まれる。

## 決定

- 素材の文書で、ひらがなだけで書かれた活用しない語を、解析器がどの表記に正規化するかで数える（`just kana-readings`。あした → 明日 293、あす → 明日 196）。
- UniDic と語彙全体から入る読みのコストは、その読みのかな書きの、表記のかな書きの中での割合を、表記の回数に掛けた回数から決める。割増 1000 のほうが安ければ、そちらにする。
- 解析器が表記に最も多く付ける読みのかな書きが 2 回に届かなければ、割合からは分からないので、その読みのかな書きの回数そのもの（表記の回数まで）を使う。
- 次の読みは見積もらない。2 回以上かなで書かれていないもの、同じ表記の別の読みの頭を濁らせたもの（木 の ぎ。語の中にしか立たない）、1 字のもの（彼 の か。解析器が助詞や語の切れ端から取り違える）。
- 何 と助数詞の語（何時）で、文章に 2 回以上出たものに、三 と助数詞の語（三時 さんじ）の さん を なん にした読みの行を入れる。コストは、表記のすべての読みを合わせたコストと、助数詞のコストに十の数のうちの 1 つを選ぶ分を足したものの大きいほう。
- 見積もった読みは、並べ替えのモデルの学習でも、その割合の所で打つ（明日 → あした → 明日）。どの所で打つかは文書 ID と位置のハッシュで決める。

## 検討した他の案

- 足す読みに手で書く：同じ形の行は数百あり、手では足りない。
- 割増を一律に小さくする：めったに使わない読み（明日 の みょうにち）まで同じだけ上がる。
- 一〜十 に 何 を加える：1,824 行が増え、何復習内、何酸 のような語が混ざる。何分 は なんぶん になり、何時 は解析器が 1 語に読むので作れない。
- 何 と助数詞の語のコストを、十の数のうちの 1 つと同じにする：すでに語として数えている 184 組では、助数詞のコストとの差の中央値は 403 で、230 より大きい。文章の回数を優先し、230 は下限に使う。
- 文脈で出た所ごとに読みを付け直す：見積もりで足りる。
- 学習の打ち方を増やさない：その読みでは、表記が別の語の誤りの候補としてしか学習に出ず、後ろに下がる。

## 結果

2026-11-24 に測った数字。

- あした で 明日（946、晨 は 1418）、なんじ で 何時（1095、汝 は 1104）が、モデルなしでもありでも先頭に出る。みんな の 皆、わたし の 私 も先頭に出る。何 と助数詞の語は 24 行が入る。
- 同じ素材で作り直して比べると、素材の文書での評価の候補に出ない単位（10,243）は変わらない。損失はモデルなしで 23,423 から 23,852 になる。モデルありは −14,366 から −13,706、すべての追加辞書を足してモデルありは −13,080 から −12,426 になる。この評価は解析器の読みで打つので、明日 はいつも あす で打たれ、あした で 明日 が出るようになったことは現れない。わたし の ワタシ、ほんと の ホント、なんじ の 汝 が先頭でなくなったことだけが損失になる。
- 確かめの語の異字同訓の第一候補は、公開する素材で作り直した辞書で、モデルなし 453、モデルあり 544（904 のうち）。
- かな書きのない読み（うち の 家、そば の 側）は今までどおり割増を足すので、並びは変わらない。
- なんじ 何事、なんそつ 何卒 のような誤った行も入るが、コストが大きく、ふつうの語より後ろになる。
