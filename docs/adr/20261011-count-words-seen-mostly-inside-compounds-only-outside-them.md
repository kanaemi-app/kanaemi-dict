# ほとんど複合語の中にしか出ない語は、複合語の外に出た回数で数える

状態：採用

## 背景

文章は C 単位で切り、B 単位に分けて数える（`20261007-count-compound-words-as-the-analyzer-groups-them.md`）。B 単位は複合語の中でも 1 語と数えるので、ほとんど複合語の中にしか出ない B 単位も、ふつうの語と同じコストになる。危機一髪・間一髪 の 一髪 は 1309 で、いっぱつ と打つと 一発 とほぼ並んでいた。素材で単独の語と数えた 一髪 50 回のうち、39 回は複合語の中だった。

同じ形の語は多い。前方後円墳 の 後円墳、花澤香菜 の 香菜、厚生労働省令 の 労働省令、主系列星 の 系列星、フルネームの中の名（由紀恵）。Kanaemi は読みを語に区切って変換しない（打つ人が区切る）ので、こうした語は、その読みで単独に打ったときに、ふつうの語の前に出るだけになる。複合語そのものは、1 語として辞書にある。

並べ替えのモデルも、B 単位を 1 語ずつ打って学習する。花澤香菜 は かな と打つ例になり、モデルは かな で 香菜 を先に出すことを学ぶ。辞書で 香菜 を下げても、モデルが 仮名 より前に戻した。

## 決定

- 活用しない B 単位の語のうち、表記が出たところ（読みを問わない）の 3/4 以上が、同じ位置の複合語の中にあるものを、切れ端とする。数値の単位と活用する語には当てない。
- 切れ端の表記の語は、複合語の外に出た回数だけを数える。外に 2 回以上出なければ、辞書に入らない（UniDic にあれば、UniDic の語として入る）。
- 並べ替えのモデルの学習では、切れ端の表記で複合語の中にある B 単位を、例にしない（打つ人は複合語として打つ）。切れ端は、学習用の辞書と同じ単位から同じ規則で決める。
- 割合は表記ごとに見る。解析器は単独の 日本 を にっぽん、複合語の中を にほん と読む（にほん 2,754 回のうち 2,743 回が複合語の中）ので、読みごとに見ると、単独でもよく打つ にほん 日本 まで切れ端になる。

## 検討した他の案

- 複合語の中の B 単位をすべて数えない：大学 の 66%、東京 の 46% が複合語の中で、ふつうの語のコストが軒並み上がる。
- 隣に漢字・カタカナが続く区切りも切れ端の場所とする（間 を ま と読んで複合語にならなかった 間一髪）：5 万〜10 万行に及び、ほとんどが名前と名字だった。
- 消さずに、最も低い帯のコストで残す：人名は人名辞書で引ける（人名辞書は基本辞書にない名を入れるので、基本辞書から外れた名は人名辞書に入る）。残りの語の多くは複合語の外では使われず、単独の読みの候補を増やすだけになる。
- 3/4 より高い割合：一髪（0.78）を拾えない。
- 学習はそのまま B 単位で打つ：モデルが切れ端を先に戻す（かな で 香菜 が 仮名 より先）。

## 結果

- いっぱつ の 一髪 は 1460 になる。
- 新聞（765 → 907）、株式、大臣、金融、主義 のような、複合語の中に多く出る語もコストが上がるが、同じ読みの中の順位は変わらない。
- 基本辞書から 3,751 行が外れる。見本 150 行では、名前の片割れ 53%、地名の一部 11%、切れ端 23%、複合語の外で使われない語 13%（労働省令、塩素酸）。人名辞書を作り直すと、そのうち 448 行が人名辞書に入る。
- 素材の文書での評価は B 単位で打つので、複合語を区切って打った分だけ下がって見える。モデルなしで下がった単位の 96% は、複合語が 1 語として辞書にある B 単位だった。
