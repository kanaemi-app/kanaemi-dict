# 解析器が分ける語を 1 回で打つ手間は、ほかの IME が 1 語で変換する連なりで測る

状態：提案

## 背景

Kanaemi は読みを語に区切らない。打つ人が区切りを決め、1 語ずつ変換する。打つ人は 起動時、有効化、接続先、経営会議 のような語を 1 回で打つ。解析器はこれらを 起動／時、有効／化、接続／先、経営／会議 に分け、C 単位にもまとめない。基本辞書は解析器がまとめる複合語しか持たないので、これらの語は辞書になく、打つ人が 1 語ずつ登録していた（起動時、有効化、接続先、表示名、構成図、従量課金、取引停止、自己点検、経営会議、法人契約、出現頻度、脅威度、残作業、隔離環境、再連携）。

素材の文書での評価は、打つ単位を解析器の区切りで決める（`20261012-measure-missing-words-and-the-loss-against-the-best-order.md`）。辞書にない複合語は、その中の単位に分けて打つ（`20261012-type-a-compound-the-dictionary-lacks-as-its-parts.md`）。解析器がまとめない 起動時 は、はじめから 起動 と 時 として打つので、辞書に 起動時 がなくても数字は下がらない。足しても上がらない。この穴は評価に見えない。

測るには、どの並びを打つ人が 1 回で打つかを決める正解が要る。その正解を、辞書に入れる決まりと同じもの（何回出たか、どれだけ離れて出るか）で決めると、評価は辞書が自分の決まりを再現できたかを測るだけになる。

## 決定

- 正解は、Mozc の辞書（`dictionary_oss`、commit を固定する）の語の一覧にする。ほかの IME が 1 回で変換する語の一覧で、辞書を作る決まりとは独立している。辞書を作るときにはこの一覧を使わない。評価にだけ使い、辞書には写さない。
- 打つ単位のうち、隙間なく隣り合い、漢字・カタカナ・長音符だけで書かれた単位の並びの中で、2 つ以上の単位をつないだ表記が一覧にあるところを、1 語で変換する連なりとする。解析器がまとめて 1 回で打つ複合語も、並びの 1 つの単位になる。並びの先頭から最も長いものを取り、その後ろから続けて探す。
  - 最後の単位が数を含む単位の連なり（一月一日）は、数を含む単位で打つので取らない。
  - 漢字を含まない表記は、読みのカタカナが候補に足されるので取らない。
  - 読みは、一覧の読みのうち、単位の読みをつないだものと同じか、つなぎ目の濁りと っ だけが違うもの。そうした読みがなければ、打つ人が何と打つかが決まらないので取らない。
- 連なりは、打つ単位とは別に、その前までの文を打ってから 1 回で変換する。候補に出なければ、打つ人は中の単位に分けて打つ。変換は単位の数より 1 回少ないだけ増える。
- 数えるのは、連なりの数、候補に出ない数、増える変換の回数、1 位の数と最善の並びに対する損失。`evaluation.tsv` の `chain` の行と、候補に出なかった連なりの表 `evaluation-chains.tsv` に書く。打つ単位の数字は変わらない。
- 利用者が登録していた語は、確かめの一覧（`evaluation/checks.tsv`）に、候補に出ることを期待する項目として置く。

## 検討した他の案

利用者が登録していた語のうち名詞の連なり（単押し を除く 15 語と、無期雇用型、有期型、正常系）が、それぞれの一覧にあるかも数えた。

| 正解 | 利用者の語 | 辞書の決まりとの関係 |
| --- | --- | --- |
| Mozc の辞書（この決定） | 14 / 18 | 独立 |
| Wikipedia の記事とリダイレクトの見出し | 0 / 18 | 語の組の決まり（`20261007-take-words-named-by-wikipedia-titles-and-redirects.md`）が使う |
| SudachiDict の語彙全体 | 0 / 18 | 解析器の辞書なので、語彙にある語は C 単位にまとまる |

- 正解を辞書の決まりと同じ統計で決める：辞書の決まりを変えると正解も変わり、決まりの比べにならない。
- Wikipedia の見出し：利用者の語がひとつもない。語の組の決まりがすでに使っているので、その分は辞書が正解を写せたかを測ることになる。
- SudachiDict の語彙全体：解析器が使う辞書なので、語彙にある複合語はもう C 単位にまとまって、打つ単位として測られている。
- 正解を決めず、並びを最も少ない変換で打つ回数を数える：辞書に入れる行が多いほど回数は減り、断片（厚生労働）や境目をまたぐ組（項又）を入れても良くなって見える。
- 連なりを打つ単位に組み込み、複合語と同じく、候補に出なければ分けて打つ：打つ単位の数字がすべて変わり、これまでの値と比べられない。正解の一覧が変わるたびにも変わる。別に数えれば、打つ単位の数字はそのまま残る。
- 利用者が登録していた語だけを正解にする：数が少なく、ひとりの分野に偏る。人が思いついた語を正解集に入れない決まりにも外れるので、確かめの一覧に置く。

Mozc の辞書にも、断片（日本経済、厚生労働 に当たるもの）やまれな組が入っている。正解の誤りは、どの辞書にも同じにかかるので、辞書どうしの比べは崩さない。候補に出ない数をそのまま「打つ人の手間」と読むと、断片の分だけ多く見積もる。

## 結果

- 学習用の文書だけの基本辞書（この記録の前のもの）で、評価用の文書の 1 語で変換する連なりは 33,551、そのうち候補に出ないのは 27,602（82.3%）、増える変換は 28,139 回、1 位に出たのは 5,715 だった（2026-11-08）。打つ単位の数字（候補に出ない 10,123、損失 21,850）は、連なりを数える前と同じだった。候補に出ないものの上位は 登場作品、送料無料、牙王、使用デッキ、日本代表、関連記事。牙王 のように一つの文書が何百回も書く連なりもあるので、上位は文書の偏りも映す。
- `just kanji` が Mozc の辞書の語の一覧も取得する。評価の前に要る。
- 辞書を変えても、正解の一覧と打つ単位は変わらないので、連なりの数は同じまま比べられる。
- 一覧にない語（隔離環境、残作業、無期雇用型、有期型）は、この数字に入らない。確かめの一覧で見る。
