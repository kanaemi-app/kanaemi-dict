# 他の辞書の項目一覧は、文章から作れない語に要り、再配布と改変が明記されているときに取り込む

状態：採用。「文章は解析にだけ使い、素材のライセンスは問わない」（`20261004-read-any-text-for-analysis-only.md`）の「他の IME や辞書の項目一覧は取り込まない」の行と、「地名は郵便番号データの一覧から取る」（`20261004-take-place-names-from-the-postal-code-list.md`）の「例外は、公的機関が配る地名の一覧に限る」の行を置き換える。

## 背景

他の IME や辞書の項目一覧は、取り込まないとしてきた。データベースの著作物や不法行為として、素材のライセンスとは別に問題になりうるため（素材の扱いの根拠、による）。例外は、自由に配ってよいと明記された郵便番号データの地名だけだった。

ところが、文章からは作れない語がある。漢字一字の読み（すで 既）は、文章で一字が単独にその読みで使われないので、文章からは生まれない。`すで*に 既に` はあっても `すで 既` はなく、漢字だけが分かる語を一字ずつ組み立てて打つ手段がない。記号や絵文字も、読みで打つ項目を文章からは作れない。

取り込まないとしてきた理由は、ライセンスの問題を避けることにあった。再配布と改変がライセンスで明記された一覧なら、UniDic の語彙（BSD-3-Clause）を取り込んでいるのと同じで、この問題は起きない。

## 決定

- 他の辞書の項目一覧は、次の 2 つを満たすときに取り込める。
  - 文章からは作れない語に要る。文章から作れる語は、今までどおり文章から選ぶ。
  - ライセンスで、再配布と改変が明記されている。
- 取り込むときは、どの一覧から、どの版を、何のために取るかを、それぞれの ADR に書く。版は固定し、配布物の NOTICE に表示を入れる。
- 語を足さずに、他の一覧の読みを辞書の読みの確かめに使う（食い違いを人が見て訂正の語に書く）のは、取り込みに当たらない。
- SudachiDict core・full と NEologd の語彙一覧は、今までどおり取り込まない（Sudachi で読み、その語彙一覧は写さない、による）。core と full は Apache-2.0 でライセンスは通るが、その語は文章から作れるので「要る」に当たらない。

## 検討した他の案

- 今の「取り込まない」のままにする：漢字一字の読みや記号を打つ手段がないままになる。
- ライセンスだけで決める：SudachiDict core まで丸ごと入り、文章から作る辞書でなくなる。並び順も文章で決められない。
- 語の読みを他の一覧で自動で置き換えるところまで含める：取り込んだ読みに表示の義務（IPAdic など）が付き、どの読みが文章由来かが追えなくなる。食い違いを人が確かめる形で足りる。

## 結果

- 漢字一字の読み、記号・絵文字・顔文字のような、文章から作れない語を、条件を満たす一覧から入れられる。
- 取り込む一覧ごとに ADR と NOTICE が増える。
- 文章から作れる語の選び方は変わらない。
