# 解析器がまとめる複合語も語として数える

状態：採用

## 背景

辞書の語は、解析器が文章を切った区切りから数える。区切りは Sudachi の B 単位（短い区切り）で、平安時代 は 平安／時代、夏目漱石 は 夏目／漱石、露天風呂 は 露天／風呂 に分かれる。辞書には、それぞれの部分はあっても、ひとまとまりの語がない。へいあんじだい や なつめそうせき とまとめて打つと、何も出ない。

部分の読みは、複合語の中での読みのまま数える。露天風呂 の 風呂 は ぶろ、株式会社 の 会社 は がいしゃ と読まれ、ぶろ 風呂 や がいしゃ 会社 という、単独では打たない項目ができる。

素材の文書での評価は、正解の区切りも B 単位なので、この穴が数字に出ない。人が書いた正解集で測ると、四字熟語・姓名のそろった人名・複合語がほとんど引けない。

Sudachi は、同じ文を C 単位（長い区切り）でも切れる。C 単位の区切りは B 単位をいくつかまとめたもので、平安時代＝へいあんじだい、露天風呂＝ろてんぶろ、株式会社＝かぶしきがいしゃ のように、複合語に複合語としての読みが付く。

## 決定

- 文章を C 単位で切り、それを B 単位に分ける。B 単位からの語の数え方は変えない。
- 2 つ以上の B 単位をまとめた C 単位のうち、名詞のものを、B 単位の語とは別に、活用しない語として数える。数詞を含むものは数えない（数を含む語は数値の項目にする）。
- 足切りは B 単位の語と同じ。文章に 2 回以上出た複合語だけが辞書に入る。
- C 単位の中の、先頭でない名詞の B 単位で、読みの最初のかなが濁っていて、その表記を UniDic が濁らない読みでも読むときは、その濁らない読みで数える（風呂 を ふろ、会社 を かいしゃ）。
- 訂正の語は、表記が同じ複合語にも当てる。外す語の表記の複合語は数えない。
- 素材の文書での評価と、並べ替えのモデルの学習は、B 単位だけで行う。複合語は B 単位と重なるので、同じ文字を 2 度打つことになる。

## 検討した他の案

- 隣り合う B 単位の組を数えて複合語にする（名詞・接辞の並びが 3 回以上）：以前の実験で、正解も B 単位の評価では差が出なかった。組の読みは部分の読みをつないだものなので、連濁が付かない（露天ふろ）。どこで区切るかを自分で決めることになる。
- 複合語を数えず、部分を順に変換してもらう：辞書の作り方は簡単だが、ひとまとまりで打つ使い方に応えられない。部分の連濁の読み（ぶろ 風呂）を残すことになる。
- 解析器の辞書の複合語の見出しを取り込む：文章に出ない語まで入り、他人の語彙一覧を写すことになる（Sudachi で読み、その語彙一覧は写さない、による）。
- 区切りをすべて C 単位にする：評価の正解と並べ替えのモデルの学習が変わり、部分だけを打ったときに引ける語が減る。

## 結果

- 辞書の項目が増える。
- C 単位でもまとまらない語（一石二鳥 を 一石＝いちこく／二鳥 と読む）は、訂正の語でつながない限り入らない。
- 連濁で読まれた部分の項目（ぶろ 風呂）は、複合語の中に出たものは入らなくなる。
- 複合語の効き目は、素材の文書での評価には出ない。正解集（`evaluation/words.tsv`）で測る。
