# 四字熟語やことわざは、Wikipedia の記事の見出しからも基本辞書に取る

状態：採用

## 背景

四字熟語、故事成語、ことわざ、慣用句は、ひとまとまりで打つ語である。解析器は、辞書に見出しのないものを短い語に分ける。C 単位でもまとまらないものがあり（一石二鳥、一期一会）、読みも誤る（一石 を いちこく）。

四字熟語の一覧を素材にすれば揃うが、他人の語彙一覧を写すことになる（Sudachi で読み、その語彙一覧は写さない、による）。一覧の多くはライセンスも辞書と合わない。

分野の辞書は、Wikipedia のカテゴリの記事から作り、記事の見出しが文書に語として出れば、本文が示す読みで項目にしている。Wikipedia には、四字熟語やことわざのカテゴリがあり、記事の冒頭に読みがある。

## 決定

- 基本辞書は、`base/wikipedia.txt` のカテゴリの記事の見出しを、読みとともに取る。カテゴリは四字熟語、故事成語、ことわざ、慣用句。
- 見出しが基本辞書の文書に語として 2 回以上出たときだけ、活用しない語として入れる。コストは、文書に出た回数から決める。
- 読みは記事の冒頭のもの。解析器の読みは使わない。

## 検討した他の案

- 四字熟語の一覧を取り込む：他人の語彙一覧を写すことになる。文書に出ない語まで入る。
- 訂正の語で一つずつつなぐ：漏れたものを人が見つけて足すしかない。
- 分野の辞書と同じく、追加辞書にする：分野によらない語なので、基本辞書だけを使う人が引けない。

## 結果

- 文書に出る四字熟語やことわざは、解析器が分けても基本辞書に入る。
- 文書に出ないものは入らない。
- Wikipedia に記事のない四字熟語は入らない。訂正の語でつなぐ。
- 見出しを集めるのに、Wikipedia のダンプを 1 度読む手順が増える。
