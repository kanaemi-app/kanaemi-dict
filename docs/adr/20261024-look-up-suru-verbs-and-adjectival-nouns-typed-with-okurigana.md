# サ変動詞と形容動詞の語幹は、送り仮名を指定して打っても引けるようにする

状態：採用

## 背景

SKK の大きな辞書（SKK-JISYO.L）は、サ変動詞の語幹と形容動詞の語幹も送り仮名付きの見出しに持っている（かんけいs の 関係、せんさいd の 繊細、ゆうりn の 有利）。SKK に慣れた人は 関係する を かんけい*す、繊細だ を せんさい*だ と打つ。

解析器は 関係した を 関係（名詞、サ変可能）と し（動詞、サ行変格）に、繊細な を 繊細（形状詞にもなる名詞）と な（助動詞 だ）に切る。する と だ は助詞ではないので、`20261024-look-up-a-word-before-a-particle-typed-with-the-particle-as-okurigana.md` の行はできない。基本辞書には、関係だ・勉強な のように、元になる語がたまたまあった行だけがあった。SKK-JISYO.L の見出しのうち、SudachiDict の語彙がサ変動詞の語幹とする語（s の行）は 134 のうち 16、形容動詞の語幹とする語（d と n の行）は 153 のうち 50 しか引けなかった。

Kanaemi の活用表はサ行変格を持ち、語幹は する の前まで（勉強）。送り仮名を指定して打つと、語幹の後ろに付いてよい読みの始まりも候補にする（かんけい*す の 関係す）。そのまま打っても活用形を出す（かんけいした の 関係した）。語幹から作る候補のコストには、Kanaemi が 500 を足す。だ の活用は活用表にない。

## 決定

- 解析器が単位のすぐ後ろに読んだ する（動詞、サ行変格）の形を、単位に持たせる（関係 の し）。だ（助動詞-ダ）の形は、単位の最後の語が 形状詞 か、形状詞にもなる名詞（形状詞可能、サ変形状詞可能）のときだけ持たせる（繊細 の な、有利 の に）。ほかの名詞の後ろの だ（学生だ）は語をつなぐだけで、SKK も見出しにしない。
- する の前の、表記が漢字で終わる活用しない語の単位を、サ行変格の語幹としても数える（`かんけい	関係	サ行変格`）。語幹と同じく、2 回以上出たものを入れる。語そのもの（`かんけい	関係`）は今までどおり数える。
- だ の前の、表記が漢字で終わる形容動詞の語の単位と、だ の形の最初のかなから、送り仮名付きの語の行を作る（せんさい*な 繊細な）。組を数え、2 回以上出たものを入れる。コストは助詞を送り仮名とする行と同じく、組の数から決めたコストに 400 を足す。
- 並べ替えのモデルは、する と だ の前のこれらの単位を、その最初のかなを送り仮名として打つ打ち方（かんけい*し → 関係し、せんさい*な → 繊細な）でも学習する。確定履歴に入れるのは、これまでどおり単位ごとに 1 回。
- 素材の文書での評価は、これまでどおり単位だけを打つ。

## 検討した他の案

数字は、学習用の文書だけの辞書でのもの。2 から 4 番目の案のモデルありの数字は、追加辞書でも学習する前の学習のしかたでのもので、そのときの #7 の辞書では −11,903。

- サ変動詞も、助詞と同じく送り仮名付きの語の行で持つ（10 回以上、400 を足す）：評価の損失はモデルなしで変わらず（21,820）、モデルありで −11,733。サ変動詞の語幹を送り仮名を指定して打つと 4.48% が候補に出ない。語幹で持つと 0.61% で、モデルありの損失も −11,802 と小さい。行は す・し・さ・せ ごとに要るが、語幹は 1 行で済み、そのまま打つ かんけいする も引ける。
- 行で持ち、サ変動詞も形容動詞も 2 回以上で入れる：候補に出ない語は 1.38% まで減るが、モデルありの損失は −11,715 で、語幹で持つより大きい。基本辞書は 24.9MB になる。
- 形容動詞の行も 10 回以上で入れる：形容動詞の語幹を送り仮名を指定して打つと 3.49% が候補に出ない。2 回以上なら 0.79%。だ はそれだけで語の送り仮名のすべてなので、まれな助詞のように語と分けて打つことはない。行も、2 回以上で約 5,900 と少ない。
- 形容動詞も、Kanaemi の活用表に だ を活用する型を足して語幹で持つ：辞書だけでは決められない。
- モデルの学習に足さない：評価の損失（単位だけを打つ）は、モデルありで −11,676（足すと −11,500）と小さいが、サ変動詞の語幹を送り仮名を指定して打つ損失が 119 から 2,818 に、形容動詞では 204 から 1,657 に増える。モデルなしの 683 と 275 より大きく、モデルがこの候補を下げることを学ぶ（`20261008-train-the-ranking-model-on-every-way-a-form-is-typed.md` と同じ形）。

## 結果

2026-10-24 に測った数字。

- かんけい*す・かんけい*し・かんけい*さ で 関係す・関係し・関係さ が、せんさい*だ・せんさい*な で 繊細だ・繊細な が引ける。かんけいした のように、そのまま打っても引ける。
- SKK-JISYO.L の見出しのうち、引けるものは、サ変動詞の語幹で 134 のうち 16 から 130 に、形容動詞の語幹で 153 のうち 50 から 122 になった。残りは 粋、朧、恣 のような、文書にまれな語。
- 基本辞書にサ行変格の語幹が約 9,400、だ を送り仮名とする行が約 5,600 入り、ファイルは 24.1MB から 24.7MB になる。文書から作る追加辞書にも、その分野の文書に出た語幹と行が入る。
- 素材の文書での評価（単位だけを打つ）の損失は、モデルなしで 21,820 から 21,850 になる。増えた分は、語幹から作る活用形をそのまま打つ読みで、名詞より先に出るもの（せつぞくし で 接続し が 接続詞 より先、ほごし で 保護し が 保護司 より先）。モデルありでは −11,610 から −11,500 になる。追加辞書をすべて後ろに置くと、モデルなしで 22,433 から 22,464、モデルありで −10,240 から −10,284 になる。
- 評価用の文書で、する の前の語を送り仮名を指定して打つと（約 8.8 万単位）、損失はモデルなしで 683、学習に足したモデルで 119。だ の前の形容動詞の語では（約 3.5 万単位）、モデルなしで 275、学習に足したモデルで 204。足す前の辞書では、それぞれ 96.7% と 82.4% が候補に出なかった。
- 正解集（モデルあり）の、文の後ろで第一候補になる語は 532 から 526 になった。モデルなしは 448 のまま。
