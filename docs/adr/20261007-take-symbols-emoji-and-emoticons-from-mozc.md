# 記号・絵文字・顔文字は Mozc の一覧から取り、それぞれ追加辞書にする

状態：採用

## 背景

記号（→、※、㎡）、絵文字、顔文字は、読みで打てると便利だが、文章からは読みで打つ項目を作れない。文章に記号が出ても、その記号の読みは書かれていない。文章から作れない語なので、条件を満たす他の一覧から取れる（他の辞書の項目一覧は、文章から作れない語に要り、再配布と改変が明記されているときに取り込む、による）。

Mozc は、記号の表 `src/data/symbol/symbol.tsv`、絵文字の表 `src/data/emoji/emoji_data.tsv` と `manual_emoji_data.tsv`、顔文字の表 `src/data/emoticon/emoticon.tsv` を持つ。どれも、文字と、空白で区切った読みの並びを持つ。リポジトリ全体が BSD-3-Clause で、再配布と改変が認められている。`emoji_data.tsv` の読みは Unicode CLDR の注釈から作られている（`manual_emoji_data.tsv` に、CLDR にある読みは足さないとある）。

Mozc の読みは、Kanaemi で打つ形と違うものがある。Kanaemi の読みは打った文字の並びそのもので、既定のローマ字の表は、英字を除く ASCII の印字可能な文字を全角にし、`- , . [ ] / ~` を `ー 、 。 「 」 ・ 〜` にする。Mozc の読みの `#` や `.` は、そのままでは打てない。英字の読み（`ok`）は、かなになるので打てない。

## 決定

- 記号、絵文字、顔文字を、それぞれ追加辞書 `symbol`、`emoji`、`emoticon` にする。基本辞書には混ぜない。
- Mozc の表から取る。単漢字の表と同じ commit に固定する。絵文字は `emoji_data.tsv` と `manual_emoji_data.tsv` の読みを合わせる。
- 読みは、既定のローマ字の表で打った形に直す。
  - 英字を除く ASCII の印字可能な文字は全角にし、`- , . [ ] / ~` は `ー 、 。 「 」 ・ 〜` にする。
  - カタカナはひらがなにする。
  - 直した後に、ひらがなと長音符、打って出る全角の文字のほかの文字（英字、漢字、空白）が残る読みは捨てる。
- 記号の表の変体仮名（Unicode の Kana Supplement と Kana Extended-A の字）は取らない。表示できるフォントが少なく、Mozc も既定では出さない。読みが え・か のような一字のかななので、ふだんの変換の候補に混ざる。
- 読みが表記と同じ組は書かない。Kanaemi は打ったとおりの読みを候補に出す。
- 項目の説明（Mozc の「真上位集合」のような注釈）は持ち込まない（注釈は辞書に持たない、による）。
- 同じ読みの中では Mozc の表の順に並べる。コストは `8192 + 読みの中の順番`（16383 で止める）にする。並べ替えのモデルの帯 13 で、基本辞書のどの語よりも後ろに並ぶ（星 の後に ★、猫 の後に 🐱）。
- 記号、絵文字、顔文字は語ではないので、基本辞書の語の形の決まり（空白を含まない、`〜` で終わらない など）は当てない。顔文字は空白を含む。

## 検討した他の案

- 基本辞書に混ぜる：ほし で ★、ねこ で 🐱 が出ることを、利用者が選べない。漢字一字の読みと違い、並べ替えのモデルが見る必要もない。
- 1 つの追加辞書にまとめる：記号はほしいが絵文字は要らない、のように選べない。
- Unicode CLDR の注釈から絵文字の読みを作る：CLDR の日本語の注釈は読みを持たず（キーワードと読み上げの名前だけ）、読みを付ける工程が要る。Mozc はその読みを持っている。
- Mozc の読みをそのまま使う：記号や英字を含む読みは打てないので、行が増えるだけになる。

## 結果

- 追加辞書を足すと、やじるし で →、まる で ○、にこにこ で (^^) のように打てる。
- Mozc の版を上げるときは、固定した commit を変えて作り直す。
- 配布物の NOTICE に Mozc（BSD-3-Clause）の表示を入れる。絵文字の辞書には、読みのもとになった Unicode CLDR（Unicode License v3）の表示も入れる。
