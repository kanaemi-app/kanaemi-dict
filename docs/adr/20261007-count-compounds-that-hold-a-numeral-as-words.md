# 数を含む複合語も、数値の項目で表せないものは語として数える

状態：採用（`20261007-count-compound-words-as-the-analyzer-groups-them.md` の決定のうち、数詞を含む複合語を数えない行を置き換える）

## 背景

`20261007-count-compound-words-as-the-analyzer-groups-them.md` は、解析器が C 単位にまとめた名詞を複合語として数え、数詞を含むものは数えないとした。数を含む語は数値の項目にする、という考えからだった。

数値の項目は、数と、その前の接頭辞、後ろの助数詞・接尾辞しか表せない。第一次世界大戦 の 世界大戦、一眼レフ の レフ、日本一 の 日本 のように、数の前後に数値の項目にならない部分がある語は、数値の項目にも複合語にもならず、辞書のどこにも入らない。

解析器が C 単位にまとめるのは、解析器の辞書に長い語として載っているものだけで、ばらばらの語の並びはまとめない。2026-10-07 の素材では、数詞を含む C 単位は 2 回以上出るものが 691 種類で、日本一、世界一、第一次世界大戦、一人称、第一印象、二次元、一眼レフ、ルパン三世 のような語がほとんどだった。日付・条文・年号（四月一日、法第二条、平成十三年）は C 単位にならない。

## 決定

- 2 つ以上の B 単位をまとめた C 単位のうち、名詞のものは、数詞を含んでいても複合語として数える。
- ただし、B 単位が、数値の項目のまとまり（接頭辞、数、助数詞、その後ろの接尾辞）と、助数詞の付かない数だけでできている C 単位は数えない（第一子、三回忌、二階建て）。数値の項目で表せるため。
- 読みは、ほかの複合語と同じく解析器が C 単位に付けたかなにする。数値の項目のように数を置き場所にはしない。
- 複合語と数値の項目が重なってもよい（一眼レフ と `{kanji}眼`）。打ち方が違う（いちがんれふ／1がん）。

## 検討した他の案

- 数値の項目のまとまりを含み、数が 2 桁以上か「第」で始まるものも除く：法第二条 のような条文を除くための案だったが、条文は C 単位にならない。除けるのは 第一次世界大戦、第一印象、億万長者、五十肩、五十音 のような語ばかりで、2 回以上出るものの半分近くを失う。
- 数が 一〜十・百・千・万 の一字のものだけを数える：億万長者、五十肩、五十音順 のような語を失い、数値の項目で表せる語（第一子）は残る。
- 今のまま数えない：上の語が辞書に入らないまま残る。

## 結果

- 数を含む複合語のうち、解析器の辞書に載っているものが基本辞書に入る。
- 解析器が C 単位にまとめない数を含む語（二次会、二度寝、第二次世界大戦）は、この決定では入らない。数値の項目の後ろに名詞が続くだけなので、まとまらない語の組と同じ扱いになる。
